# القرارات المفتوحة الحالية

المصدر الكامل: `03_OPEN_OWNER_DECISIONS.md`. بعد المصالحة الحالية، لا تعتبر هذه البنود مقبولة إلا إذا كانت مدعومة بتوجيه مستقل في `02_CURRENT_OWNER_DIRECTIVES`.

## قرارات يمكن تأجيلها إلى ما بعد Phase 0A
- اعتماد P1..P8 كتقسيم رسمي أو إبقاؤه خريطة تخطيط.
- اعتماد ترتيب التنفيذ المقترح كقاعدة رسمية.
- Full dual-lane Blind/External لكل جذر أو فقط للمعايرة/الجذور المهمة.
- إغلاق مراجعة شاملة لكل مصطلحات V2.1 أو الاقتصار على Human-facing delta.
- الحجم الأمثل لدفعة المعايرة.
- أي اختبارات robustness تصبح إلزامية لكل جذر وأيها حسب المخاطر.

## ما لم يعد سؤالًا مفتوحًا في الجوهر
- بناء المعرفة الوصفية قبل الاجتهاد: مقبول مالكيًا.
- فصل الحقيقة النصية عن تحليل بنيوي قابل للمراجعة: ناتج لازم من التوجيه المقبول ويجب تطبيقه بصورة محافظة.
- برنامج آثار الحروف ليس سلطة؛ يبقى فرضيات واختبارات.
- لا نحتاج Gate جديدًا افتراضيًا؛ استخدم أخف آلية إلا إذا أثبتت الحاجة.
