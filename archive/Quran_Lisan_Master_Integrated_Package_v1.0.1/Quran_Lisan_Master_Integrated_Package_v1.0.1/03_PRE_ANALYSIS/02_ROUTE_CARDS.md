## P1 — بطاقة المسار
**المشكلة:** الافتراضات الخفية قد تتحول إلى نتائج دون أن نعرف أثرها.  
**المدخلات:** أوصاف القرآن، مبادئ المنهج، قرارات المالك.  
**المخرجات:** Foundational Profile versioned.  
**لا ينبغي:** إنشاء Gate ثقيل قبل كل جذر.  
**اختبار القيمة:** هل يستطيع الباحث معرفة أي مقدمة أثرت في النتيجة؟

## P2 — بطاقة المسار
**المشكلة:** لا بحث قابل للتكرار بلا نص مرجعي وهوية ثابتة.  
**المخرجات:** CorpusSnapshot + index + exact locators.  
**الإنفاذ:** حتمي برمجيًا.  
**الوضع:** موجود أصلًا في V2.1.

## P3 — بطاقة المسار
**المشكلة:** إعادة العد والحصر بواسطة AI تسبب تكلفة وخطر خطأ.  
**المخرجات المقترحة:** RootDescriptiveProfile / TermDescriptiveProfile.  
**حقائق مباشرة:** النص، المواضع، العد، التوزيع.  
**بيانات مشتقة:** الجذر، الصيغة، التركيب؛ تربط بمصدرها وموثوقيتها.  
**قاعدة:** ما يستطيع Host إثباته لا يترك لLLM كي يخمنه.

## P4 — بطاقة المسار
**المشكلة:** اعتبار كل Morphology/Syntax «حقيقة» قد يسقط معنى جذري صحيح بسبب تحليل بنيوي خاطئ.  
**المقترح:** ثلاث حالات عرضية على الأقل: `TEXT_DIRECT`, `STRUCTURAL_QUALIFIED`, `STRUCTURAL_DISPUTED`.  
**ملاحظة:** الأسماء نفسها مقترحة وليست مصطلحات معتمدة.

## P5 — بطاقة المسار
**المشكلة:** غموض المصطلح يتضاعف حين يدخل Contracts وPrompts وDB.  
**الهدف:** اعتماد لغة واضحة قبل التوسع.  
**لا ينبغي:** كسر معرفات تقنية قائمة بلا خطة توافق.

## P6 — بطاقة المسار
**المشكلة:** لا يمكن مقارنة نتائج Batch إذا تغيرت القواعد أثناءه.  
**الهدف:** Methodology Revision ثابت لكل Batch، وشروط قبول جذر واضحة.  
**قاعدة مالكية:** الموضع المخالف الثابت الانتماء يمنع قبول معنى جذري جامع بصورته الحالية.

## P7 — بطاقة المسار
**المشكلة:** التوسع قد يضاعف خللاً منهجيًا غير مكتشف.  
**الهدف:** Calibration Set متنوعة؛ Holdout؛ Falsification؛ order sensitivity؛ sentinel roots.  
**المقترح:** لا Scale واسع قبل نجاح عينة المعايرة.

## P8 — بطاقة المسار
**المشكلة:** نحتاج تراكم المعرفة دون تلويث البحث المستقل.  
**الهدف:** فصل Accepted Knowledge عن Blind Context، وحفظ Findings/Proposals/Reopen Conditions.  
**العلاقة:** يستفيد مباشرة من Governed Intent Capture Addendum.
