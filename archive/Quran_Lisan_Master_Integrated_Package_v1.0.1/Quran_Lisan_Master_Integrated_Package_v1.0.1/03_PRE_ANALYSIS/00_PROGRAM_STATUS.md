# حالة برنامج ما قبل التحليل

البرنامج المقترح P1..P8 **لم يعتمد بوصفه تقسيمًا حاكمًا كاملًا**. بعض مكوناته صارت مدعومة بتوجيهات مالكية مستقلة (خصوصًا المعرفة الوصفية، وضوح المصطلحات، شرط شمول معنى الجذر، والاستفادة المقيدة من المصادر الخارجية).

تستخدم هذه الحزمة P1..P8 كخريطة تخطيط وتوصية فقط حتى يصدر قرار مالك بشأن البنية نفسها.
