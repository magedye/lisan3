# ورقة قرارات المالك — برنامج ما قبل التحليل

هذه الورقة لا تفترض إجاباتك. هي تجمع القرارات الحقيقية المتبقية في مكان واحد.

| القرار | السؤال | توصية المساعد | الأثر إذا اعتمد |
|---|---|---|---|
| D-PRE-01 | هل تعتمد تنظيم التحضير في P1..P8؟ | نعم، كبرنامج تنظيمي لا كثمانية Gates | يجعل المسؤوليات والتقدم قابلة للتتبع |
| D-PRE-02 | هل تعتمد ترتيب التنفيذ المقترح؟ | نعم كDefault Dependency Order مع التوازي | يقلل إعادة العمل |
| D-PRE-03 | هل تبنى قاعدة المعرفة الوصفية كمكوّن مشترك مستقل؟ | نعم | أكبر خفض لتكرار العمل وخطر اختلاق الحقائق |
| D-PRE-04 | هل تعتمد فصل الحقيقة النصية عن البيانات البنيوية المؤهلة/المختلف فيها؟ | نعم | يمنع إسقاط فرضية بسبب تحليل صرفي غير قطعي |
| D-PRE-05 | هل تُغلق مراجعة المصطلحات قبل Scale؟ | نعم للعناوين والمصطلحات الحاكمة فقط | يمنع تراكم غموض اصطلاحي |
| D-PRE-06 | هل تصبح المعايرة شرطًا قبل دفعات واسعة؟ | نعم | يمنع تكرار عيب منهجي على عشرات الجذور |
| D-PRE-07 | هل يُعتمد المسار الثنائي Blind/External؟ | أوصي به للمعايرة والجذور عالية الأهمية أولًا؛ ثم نقرر الكلفة | يقيس استقلال النتيجة دون مضاعفة التكلفة دائمًا |
| D-PRE-08 | هل برنامج آثار الحروف مانع لبدء الجذور؟ | لا | يبقى بحثًا موازيًا حتى تتراكم أدلة كافية |
| D-PRE-09 | هل ننشئ Gate جديدًا للجاهزية؟ | لا مبدئيًا؛ Checklist + hard blockers محدودة | يحقق الحماية دون governance inflation |

## صيغة الاعتماد المقترحة عند القرار
يمكن للمالك اعتماد الكل أو بعض البنود. كل قرار يجب أن يسجل في `DECISION_REGISTER` ويربط بمقترح التغيير الموافق له. لا تعتمد هذه الوثيقة أي بند تلقائيًا.
