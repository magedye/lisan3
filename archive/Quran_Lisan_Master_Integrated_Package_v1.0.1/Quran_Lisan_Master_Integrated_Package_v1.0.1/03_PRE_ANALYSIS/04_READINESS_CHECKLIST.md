# قائمة جاهزية قبل التحليل الواسع

هذه Checklist وليست Gate جديدة.

## Hard blockers قليلة
- مصدر النص الكانوني معروف ومتحقق وفق V2.1.
- لا يُدّعى حصر جميع مواضع الجذر دون بيانات قابلة للتحقق.
- لا تُستخدم ذاكرة النموذج بدل البيانات النصية/البنيوية.
- لا تخلط الفرضية الخارجية بالاكتشاف الداخلي وتصفها بأنها مستقلة.
- لا يُقبل معنى جذري لا يفسر جميع المواضع الثابتة الانتماء.

## Readiness items
- قاعدة/خدمة المعرفة الوصفية قادرة على إعطاء ملف وصفي قابل لإعادة الإنتاج للجذر.
- مصدر نسبة الألفاظ إلى الجذور والصيغ موثق، والخلاف البنيوي قابل للوسم.
- سجل Intake/Findings يعمل.
- منهجية الدفعة تحمل revision ثابتة.
- معيار القوة/الاكتمال/التحقق لا يستخدم نسبة غير معايرة.
- المصادر الخارجية مسجلة كفرضيات ذات provenance وخطة اختبار.

الدفعة الواسعة تبدأ فقط بعد إثبات هذه العناصر على عينة معايرة صغيرة.
