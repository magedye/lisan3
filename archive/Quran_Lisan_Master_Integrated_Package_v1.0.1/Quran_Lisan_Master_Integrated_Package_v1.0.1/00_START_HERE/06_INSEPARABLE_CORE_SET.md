# المجموعة الحاكمة غير القابلة للفصل أثناء التنفيذ

عند تسليم هذه الحزمة إلى أي وكيل، يجب أن تتاح له كوحدة واحدة العناصر الآتية:

1. `00_START_HERE/00_MASTER_AUTHORITY.md`
2. `00_START_HERE/02_CURRENT_STATUS_AND_VERDICT.md`
3. V2.1 داخل `01_CANONICAL_BASE/`
4. `02_CURRENT_OWNER_DIRECTIVES/`
5. `05_REGISTRIES/MASTER_SUPERSESSION_MAP.csv`
6. `04_RUNTIME_PROMPTS/CURRENT_LISAN_METHODOLOGY_PROMPT.md` عند تنفيذ بحث دلالي.
7. `02_CURRENT_OWNER_DIRECTIVES/01_GOVERNED_CAPTURE_CURRENT_POLICY.md` أثناء أي عمل ينتج قرارات أو أفكارًا أو Findings.
8. `02_CURRENT_OWNER_DIRECTIVES/03_DESCRIPTIVE_KNOWLEDGE_BEFORE_SEMANTIC_REASONING.md` قبل أي حملة تحليل واسعة.
9. `02_CURRENT_OWNER_DIRECTIVES/04_EXTERNAL_HYPOTHESIS_TESTING_CURRENT_POLICY.md` عند استخدام مصادر خارجية.

`03_PRE_ANALYSIS/` لا يصبح جزءًا حاكمًا إلا بعد اعتماد قراراته، لكنه يجب أن يبقى متاحًا بوصفه سجل المقترحات الحالية.

لا يجوز إعطاء الوكيل Prompt منفردًا من `04_RUNTIME_PROMPTS/` دون سلطة الحزمة والدلتا الحالية؛ لأن الـPrompt وحده لا يحمل كل تاريخ النسخ والتعارضات.
