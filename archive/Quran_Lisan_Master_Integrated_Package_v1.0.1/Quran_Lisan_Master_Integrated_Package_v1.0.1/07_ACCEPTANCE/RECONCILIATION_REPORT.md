# تقرير المصالحة الشاملة

## منهج المصالحة
1. حفظ جميع الحزم الأصلية دون تعديل.
2. إثبات أن النسخ المعاد رفعها مطابقة للبصمات الأصلية.
3. اعتبار V2.1 قاعدة كانونية وعدم إعادة دمج V2.0 على أساس المساواة.
4. تطبيق التوجيهات المالكية اللاحقة فقط كدلتا.
5. إبقاء المقترحات المفتوحة خارج السلطة.
6. إصدار Prompts حالية مصالحة مع حفظ النسخ السابقة.

## تغييرات ضرورية فقط
- إضافة شرط الحضور الشامل لمعنى الجذر إلى النسخ الحالية.
- إزالة الاعتماد التشغيلي على `MULTIPLE_LEXICAL_UNITS` بوصفه حلًا نهائيًا لجذر ثابت.
- إدخال المعرفة الوصفية قبل الاجتهاد.
- توسيع وظيفة المصادر الخارجية إلى hypothesis/test generation مع عزل النسبة المعرفية.
- توضيح المصطلحات Human-facing دون mass rename للعقود.
- تفعيل Governed Capture كقاعدة مستمرة.

## ما لم يتغير
- سلطة AI البحثية داخل الحدود.
- المصدر القرآني الداخلي وأولوية الاستقراء.
- الفصل بين الجذر والصيغة والتركيب والسياق.
- الدحض والبدائل والتتبع.
- الفصل بين قوة النتيجة والاكتمال والتحقق.
- عدم استخدام نسبة ثقة غير معايرة.
- عدم تعديل النتائج المعتمدة صامتًا.
- V2.1 contracts/tools/skills preserved byte-for-byte in base.

## مواد أرشيفية
V2.0 وما قبله، Prompts السابقة، والحزم المساعدة محفوظة للأثر فقط ولا تدخل سلطة التنفيذ الحالية.
