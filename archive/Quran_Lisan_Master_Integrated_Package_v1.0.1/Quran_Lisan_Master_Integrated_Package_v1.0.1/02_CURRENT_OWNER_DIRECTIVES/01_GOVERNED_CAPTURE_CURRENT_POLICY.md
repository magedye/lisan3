# سياسة التقاط الأفكار الحالية

## القاعدة
كل نقطة جوهرية تلتقط قبل تقرير موضعها النهائي:
`CAPTURE → ATOMIZE → CLASSIFY → MAP → DISPOSITION → VERIFY`.

## السلطة
- قول المالك الصريح: Owner Directive/Decision بحسب الصيغة.
- اقتراح المساعد/الوكيل: `OPEN/PROPOSED` حتى اعتماد المالك.
- Finding من التشغيل: لا يتحول إلى Rule تلقائيًا.

## المصير
لا يختفي عنصر بلا واحد من: `ACCEPTED / IMPLEMENTED / DEFERRED / REJECTED / SUPERSEDED / OPEN` مع rationale.

## الحد الأدنى للتتبع
كل Accepted item يجب أن يملك target/reference أو سببًا مسجلًا لعدم التنفيذ بعد.
