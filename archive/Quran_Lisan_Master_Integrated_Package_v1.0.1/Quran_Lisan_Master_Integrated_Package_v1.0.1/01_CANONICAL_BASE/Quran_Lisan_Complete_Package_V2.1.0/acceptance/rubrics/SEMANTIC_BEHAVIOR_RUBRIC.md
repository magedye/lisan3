# Rubric — معيار تقييم السلوك الدلالي

كل حالة تقيم 0/1 في البنود الملائمة: سلامة المصدر، فصل الطبقات، اكتمال التتبع، جدية البدائل، دحض واقعي، احترام عدم الحسم، عدم اختراع الفرق، وعدم استخدام رقم ثقة غير معاير. لا تجمع الدرجات إلى «صحة معنى» آلية. الفشل في سلامة المصدر أو اختلاق آية/Tool هو **Fail حاسم** للحالة.
