# سلطة حزمة لسان القرآن الشاملة — V2

**الحزمة:** `Quran_Lisan_Complete_Package_V2.1.0`  
**الإصدار:** `2.1.0`  
**التاريخ:** 2026-09-05  
**الحالة:** `V2.1_CANONICAL_COMPREHENSIVE_BASELINE / READY_FOR_BLIND_IMPLEMENTATION`

## 1. الغرض
V2 هي الحزمة المرجعية والتنفيذية والبحثية الموحدة للمشروع الجديد. تدمج المرجع المنهجي، الإغلاق التنفيذي، عقود البيانات والأدوات والمهارات والوكلاء، ومعيار النتيجة البحثية النهائية وسلسلة اشتقاق الدلالة. لا تتطلب الرجوع إلى حزم v1.0.0 أو v1.0.1 لاتخاذ قرار منهجي أو معماري ضمن نطاق Phase 0 والنموذج الأول.

## 2. ترتيب السلطة
1. تعليمات المالك الصريحة الحالية.
2. هذا الملف `00_PACKAGE_AUTHORITY.md`.
3. هدف المنتج والدستور المنهجي والاستدلالي والمصطلحات الحاكمة: `reference/01_PRODUCT_CHARTER_AND_SCOPE.md`, `reference/03_METHODOLOGY_AND_EVIDENCE_CONSTITUTION.md`, `reference/02_TERMINOLOGY_AND_LANGUAGE_GOVERNANCE.md`.
4. دستور حوكمة الذكاء الاصطناعي: `reference/07B_AI_GOVERNANCE_CONSTITUTION.md`، ومقدمته التأسيسية `reference/07A_AI_ADOPTION_RATIONALE_AND_EXPECTED_ROLE.md`.
5. سياسات المصادر والضوابط والسجلات والعقود الآلية داخل `reference/`, `registries/`, `contracts/` بما لا يتعارض مع المستويات الأعلى.
6. عقود Skills/Agents/Tools وبروتوكولات التنفيذ والبوابات.
7. عقود البحث والمخرجات داخل `research/`.
8. أدلة التنفيذ والقبول وFixtures.
9. `inputs/` و`history/` مواد تتبع/خبرة وليست سلطة مستقلة.

عند التعارض لا يحسم المنفذ بصمت؛ يتبع الأعلى سلطة ويسجل التعارض. السجلات الآلية صورة تنفيذية للقرارات ولا تملك نقض الدستور الأعلى.

## 3. ما لم يتغير عن الحزمة السابقة
- الاستقراء القرآني الداخلي هو المسار الأول.
- AI يملك الاستنباط والترجيح ولا يملك اختراع الدليل.
- المعرفة السابقة للنموذج والنتائج السابقة ليست دليلًا بذاتها.
- الفصل بين الجذر/الوحدة المعجمية/الصيغة/التركيب/السياق/المعنى الموضعي إلزامي.
- البدائل والنقض والحالات الصعبة وعدم الحسم عناصر أصلية.
- المصدر والهوية والتغطية والحساب والتحقق القابل للحتمية تنفذ أو تتحقق برمجيًا.
- الثقة والاكتمال والتحقق المستقل أبعاد منفصلة؛ لا نسب ثقة موثوقة قبل المعايرة.
- المصادر الخارجية لا تدخل الاستقراء الداخلي قبل إغلاق نتيجته.
- Gem/Opal قابلان للاستبدال؛ المحرك المستقل هو system of record.

## 4. الإضافة المركزية في V2
أصبح شكل النتيجة وسلسلة اشتقاق الدلالة عقدًا رسميًا قابلًا للتحقق. في التحليل الموضعي لا يجوز الانتقال إلى النتيجة النهائية قبل المرور المنظم: الجذر → التصريف/الاشتقاق العام → علاقة المفردة بالجذر → الصيغة والتركيب العامان → تحققهما الخاص → الأدوار → مقتضى السياق → المعنى الموضعي → البيان الدلالي النهائي.

## 5. معنى الجاهزية
`READY_FOR_BLIND_IMPLEMENTATION` يعني أن مطورًا جديدًا يستطيع بدء Phase 0 والنموذج الأول من V2 دون قرار منهجي/معماري غير موثق. لا يعني أن المنتج منفذ أو أن نتيجة دلالية بعينها صحيحة أو أن الثقة الرقمية معايرة أو أن CAP-GO-01 قد نجح.


## 6. إضافة V2.1 — سلطة الذكاء الاصطناعي البحثية
تثبت V2.1 المسار: `Proposal → Research Judgment → Verification → Canonical Authorization (when required)`. `SemanticDecision` هو حكم بحثي يمكنه الترجيح والرفض وعدم الحسم، لكنه لا يساوي اعتمادًا رسميًا. أمثلة نجاحات AI الخارجية تبرر اختيار الأداة والمعمارية فقط ولا تدخل دليلًا في الاستقراء القرآني الداخلي.
