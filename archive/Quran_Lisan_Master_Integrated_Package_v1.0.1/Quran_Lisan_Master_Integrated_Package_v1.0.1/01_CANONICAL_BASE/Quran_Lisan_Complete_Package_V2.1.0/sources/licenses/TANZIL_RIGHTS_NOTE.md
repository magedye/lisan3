# ملاحظة حقوق Tanzil

هذه الحزمة لا تنسخ نص القرآن من Tanzil. ملف التعريف يحيل إلى صفحة Tanzil الرسمية وشروطها. عند اقتناء/إعادة توزيع النص يجب المحافظة على نسبة المصدر وشروط النسخ الحرفي كما يحددها Tanzil. على منفذ المشروع مراجعة الشروط المنشورة وقت الاقتناء وتسجيل snapshot للرابط والتاريخ في `release-evidence/source-acquisition/`.
