# توجيه المالك الحاكم لشكل البيان الدلالي — 2026-09-05

هذا الملف يثبت الترتيب الذي يجب أن يظهر به اشتقاق الدلالة في النتيجة البحثية عندما تكون المهمة متعلقة بمفردة/معنى موضعي/آية:

1. دلالة الجذر.
2. دلالة التصريف والاشتقاق بصورة عامة ضمن النطاق المثبت.
3. دلالة المفردة وعلاقتها بجذرها.
4. دلالة الصيغة بصورة عامة.
5. دلالة التركيب بصورة عامة.
6. تحقق دلالة الصيغة في الموضع الخاص.
7. تحقق دلالة التركيب والأدوار في الموضع الخاص.
8. ما يقتضيه السياق والخطاب.
9. المعنى الموضعي المركب.
10. البيان الدلالي النهائي، مع الأدلة والبدائل والحدود والنقض والاكتمال والتحقق.

هذا الترتيب عقد منهجي/عرضي ملزم؛ لا يجوز القفز مباشرة إلى المعنى الموضعي ثم إعادة تحميل نتيجته على الجذر أو الصيغة بلا دليل مستقل.
