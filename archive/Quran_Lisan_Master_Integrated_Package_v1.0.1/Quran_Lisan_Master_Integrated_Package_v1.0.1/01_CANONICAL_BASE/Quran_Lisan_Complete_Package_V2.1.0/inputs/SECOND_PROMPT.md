## Phase 2 — Process Each Root Independently

عالج **كل جذر كوحدة بحث مستقلة**.

لا تستخدم نتيجة جذر آخر إلا وفق قواعد المعرفة التراكمية المعتمدة في مهارة لسان القرآن، وبعد تسجيل dependency/provenance المناسب.

لكل جذر:

### 1. Establish Corpus/Occurrence Scope

حدد:
- الأسرة الجذرية المؤكدة.
- جميع المواضع ذات الصلة بحسب حدود الـCorpus المعتمد.
- الصيغ.
- التراكيب.
- تنوع السياقات.
- الاستعمالات المقاومة أو الشاذة.

لا تدّعِ full coverage إن لم يثبت ذلك.

### 2. Freeze Initial Hypotheses

استخرج من المواد السابقة الفرضيات الممكنة، لكن عاملها كمرشحات لا حقائق.

افصل بين:
- hypothesis inherited from prior materials.
- hypothesis independently recovered from Quranic evidence.
- later internal Lisan knowledge.

### 3. Derive the Abstract Root Core

استخرج أقل نواة مفهومية موجبة وثابتة وقابلة للدحض.

قدمها في:

- `FORMAL DEFINITION`
- `OPERATIONAL DEFINITION`
- `CONCEPTUAL STRUCTURE`
- `SIMPLE ARABIC EXPLANATION`

ولا تستخدم أشهر ترجمة أو أشهر استعمال بوصفه Root Core.

### 4. Semantic Boundary

حدد صراحة:

- `REQUIRED`
- `PERMITTED`
- `EXCLUDED`
- `UNKNOWN`
- `LOCAL REALIZATION`

أي claim لا يدعمه الدليل يبقى `UNKNOWN` ولا يُملأ بالحدس.

### 5. Decisive Contexts

افصل بين:
- Illustrative verses.
- Decisive contexts.

حدد لكل سياق حاسم:
- ما الفرضية التي اختبرها؟
- ماذا أسقط؟
- ماذا ضيق؟
- ماذا دعم؟
- قوته الاستدلالية.
- Structural Sensitivity.
- هل تغير النتيجة إذا تغير التحليل البنيوي؟

أبرز:
- أقوى مؤيد.
- أقوى معارض.
- أصعب موضع.
- المواضع المقاومة.

### 6. Semantic Family Differentiation

أنشئ `SEMANTIC FAMILY RELATION MAP`.

لكل جار دلالي مهم، أنشئ Distinction Card تحتوي:

- Target.
- Neighbor.
- Shared Territory.
- Target Residue.
- Neighbor Residue.
- Same-context collision إن وجد.
- Counterfactual substitution.
- ما الذي يضيع عند الاستبدال؟
- Distinction status.

لا تعتبر Root Core ناجحًا إذا لم يتمكن من التفرد عن أقرب المنافسين حيث يطلب المنهج ذلك.

### 7. Morphology and Construction

حلل بصورة منفصلة:

`ROOT CORE`
`+ STEM FORM`
`+ ASPECT / VIEW`
`+ VOICE`
`+ MOOD`
`+ NOMINALIZATION / PARTICIPLE`
`+ PARTICLE`
`+ CONSTRUCTION`
`+ ARGUMENTS`

ولكل Operator:
- الاسم العربي.
- English identifier إن كان معتمدًا.
- الوظيفة.
- القيمة في الموضع.
- Evidence Scope.

لا تعمم وظيفة ثبتت محليًا على كامل القرآن دون evidence يسمح بذلك.

### 8. Derive Local Meanings

لكل استعمال رئيسي:

`ROOT CORE + FORM + CONSTRUCTION + ARGUMENTS + CONTEXT = LOCAL MEANING`

اشرح بصورة قابلة للتدقيق:
- مساهمة الجذر.
- مساهمة الصيغة.
- مساهمة التركيب.
- المشاركين.
- السياق.
- المعنى العربي الطبيعي الناتج.

استخدم هذه المرحلة أيضًا لاختبار صلاحية Root Core نفسه.

## MOA Analysis Structure

استخدم MOA في **التحليل فقط** بحيث تكون الآراء مستقلة ثم يجمعها Aggregator واحد.

أوصي بالأدوار التالية:

### Agent A — Root Core Analyst
يركز على:
- Concept Specification.
- Root Core.
- Semantic Boundary.
- derivational invariance.

### Agent B — Falsification / Adversarial Analyst
يحاول إسقاط النواة:
- resistant occurrences.
- competing hypotheses.
- counterexamples.
- overgeneralization.
- context leakage.

### Agent C — Semantic Family Analyst
يركز على:
- nearest neighbors.
- distinction cards.
- counterfactual substitution.
- distinctive residue.

### Agent D — Morphosyntax Analyst
يركز على:
- form.
- construction.
- particles.
- arguments.
- operator scope.
- Local Meaning derivation.

### Agent E — Evidence / Governance Auditor
يركز على:
- provenance.
- primary vs derived evidence.
- prior contamination.
- heritage boundary.
- statuses.
- dependencies.
- claims/evidence linkage.
- compliance with the template.

### Aggregator
هو الوحيد الذي:
- يقارن النتائج.
- يحدد مواضع الاتفاق والخلاف.
- يرفض consensus غير المدعوم.
- ينتج النتيجة المركبة.
- يبقي الخلافات غير المحسومة `UNKNOWN`.

لا تسمح لوكلاء متعددين بإجراء تعديلات متزامنة ومتداخلة على نفس الملفات.

## Stop Conditions

توقف ولا تحسم الجذر إذا تحقق أي من الآتي:

- corpus/root family غير موثوق بما يكفي.
- Root Core لا يفسر موضعًا مؤكدًا ولا توجد طبقة صرفية/تركيبية/سياقية تفسره.
- لا يمكن فصل Root Core عن أشهر Local Meaning.
- أقرب neighbor لم يتم التفريق عنه.
- يوجد counterevidence مادي غير محلول.
- evidence provenance غير قابل للتتبع.
- القالب أو Registry الحاكم متعارض ولا توجد سلطة أعلى تحسمه.

في هذه الحالات أخرج النتيجة بالحالة الرسمية غير المحسومة مع blocker/reopen condition واضح.
