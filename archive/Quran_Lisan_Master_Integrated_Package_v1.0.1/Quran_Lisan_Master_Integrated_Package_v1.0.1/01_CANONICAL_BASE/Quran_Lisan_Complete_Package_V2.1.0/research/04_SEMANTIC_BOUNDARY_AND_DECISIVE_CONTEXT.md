# الحدود الدلالية والسياقات الحاسمة

## Semantic Boundary
لكل مفهوم جذري أو نتيجة مهمة تصنف الادعاءات إلى:
- `REQUIRED`: لازم في النتيجة ضمن نطاقها.
- `PERMITTED`: متوافق مع النتيجة لكنه ليس لازمًا بكل موضع.
- `EXCLUDED`: لا يجوز نسبته إلى النواة/الكيان في النطاق المثبت.
- `UNKNOWN`: لم تحسم الأدلة إسناده.
- `LOCAL_REALIZATION`: تحقق موضعي من تفاعل الطبقات ولا يرفع إلى الجذر تلقائيًا.

## Illustrative ≠ Decisive
الشاهد التوضيحي يشرح النتيجة. أما `DecisiveContextAssessment` فيسجل سياقًا لعب دورًا فعليًا في اختبار فرضية. لكل سياق حاسم: الفرضيات المختبرة، أثره SUPPORT/NARROW/OPPOSE/FALSIFY، حساسيته للتحليل البنيوي، مراجع الأدلة، وما الذي يتغير إذا تغير التحليل البنيوي.
