# عقد التمييز بين الجيران الدلاليين

لكل جار مهم، توسع `SemanticNeighborResult` إلى Distinction Card تتضمن:
- target / neighbor.
- shared territory.
- target residue.
- neighbor residue.
- tested dimensions.
- same-context collisions إن وجدت.
- counterfactual substitution cases.
- ما الذي يضيع أو يتغير عند الاستبدال.
- established differences.
- unresolved differences.
- disposition.

اختبار الاستبدال الافتراضي أداة استكشاف/تحدٍ وليس دليلًا مستقلًا. وعدم إثبات الفرق نتيجة مشروعة؛ لا يخترع النظام فرقًا لحماية مبدأ عدم الترادف التام.
