# بروتوكول MOA للمراجعة البحثية العميقة

MOA (تحليل متعدد الزوايا بواسطة وكلاء/جلسات) **وضع مراجعة اختياري**، وليس العمارة الافتراضية لكل سؤال. يستخدم عند تأهيل جذر مهم، تعادل فرضيات، نتائج ذات أثر كبير، أو اختبارات regression.

## الأدوار التحليلية
- Root Core Analyst: المفهوم والحدود والثبات عبر الاشتقاق.
- Falsification Analyst: الحالات المقاومة والمنافسون والأمثلة المضادة والتعميم الزائد.
- Semantic Family Analyst: الجيران، Distinction Cards، والسمة الفارقة.
- Morphosyntax Analyst: التصريف/الاشتقاق والصيغة والتركيب والأدوار واشتقاق المعنى الموضعي.
- Evidence/Governance Auditor: provenance، source classes، dependencies، contamination، template conformance.

## Aggregator
AG-01 أو جلسة تجميع منفصلة تقارن المخرجات وتحافظ على الخلافات. `MOA consensus` لا يرفع claim إلى Evidence ولا يعوض غياب الشاهد. استقلال المراجعة يسجل وفق نوعه الفعلي؛ تكرار النموذج والسياق نفسه ليس استقلالًا.

## منع التداخل
لا تعدل جلسات MOA السجلات الحاكمة بالتوازي. تنتج Findings مستقلة ثم يربطها Aggregator بالقرار عبر Evidence/Verification contracts.
