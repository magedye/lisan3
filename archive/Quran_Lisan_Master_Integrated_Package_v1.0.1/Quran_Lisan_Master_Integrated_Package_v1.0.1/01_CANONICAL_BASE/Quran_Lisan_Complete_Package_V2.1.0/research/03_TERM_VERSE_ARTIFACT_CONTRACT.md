# عقد دراسة المفردة والمعنى الموضعي والآية — V2

## A. TermResearchArtifact
يحدد أولًا `scope = LEXEME | LOCAL_MEANING`. الحقول الجوهرية:
- TERM / LEMMA / ROOT / الموضع عند الانطباق.
- هوية الوحدة المعجمية أو فرضيتها.
- SemanticDerivationChain كاملة عند LOCAL_MEANING.
- مساهمة الجذر.
- التصريف والاشتقاق العامان ثم أثرهما في المفردة.
- الصيغة العامة ثم تحققها الخاص.
- التركيب العام ثم تحققه الخاص.
- Arguments/Semantic Roles.
- مقتضى السياق والخطاب.
- المعنى الموضعي.
- البدائل وسبب رفض/بقاء كل بديل.
- الأدلة والمعارضات وUnknowns.
- Reopen conditions.

## B. VerseSemanticAnalysisArtifact
عندما يكون السؤال عن آية/مقطع، لا تساوي خلاصة الآية معنى الجذر. لكل مفردة محورية يتكرر تحليلها الطبقي ثم تركب الخلاصة على مستوى الآية.

### ترتيب العرض للفظة المؤثرة
دلالة الجذر → التصريف/الاشتقاق العام → المفردة وعلاقتها بالجذر → الصيغة العامة → التركيب العام → الصيغة الخاصة → التركيب/الأدوار الخاصة → مقتضى السياق → المعنى الموضعي.

### خلاصة الآية
بعد تحليل الألفاظ/التراكيب المؤثرة، يصاغ المعنى الإجمالي ضمن نطاق السؤال فقط، مع بيان ما تثبته الآية وما لا تثبته وحدها وما لا يجوز تعميمه على الجذر.
