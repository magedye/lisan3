# تأهيل المواد السابقة ومراجعة الاتساق عبر الجذور

## 1. PriorClaimAssessment
لا تعامل مادة سابقة كصحيحة أو خاطئة لمجرد قدمها. تسجل كادعاء سابق مع origin/provenance، ثم يصنف تحليليًا إلى: SUPPORTED_BY_CURRENT_METHOD، SUPPORTED_WITH_REFINEMENT، PARTIALLY_SUPPORTED، INSUFFICIENT_EVIDENCE، CONTEXT_LEAKAGE، FORM_ROOT_CONFLATION، HERITAGE_PRIOR_CONTAMINATION، OVERGENERALIZED، FALSIFIED، UNRESOLVED. هذه dispositions ليست حالات معرفية عامة للنتيجة.

## 2. الأثر التدقيقي
لا تمح المادة المخالفة؛ احفظ ما تغير ولماذا وروابط الأدلة الجديدة.

## 3. CrossRootConsistencyReview
بعد تجاوز Pilot إلى دفعات جذور، افحص اتساق: تعريفات الصيغ، وظيفة التراكيب، استعمال المصطلحات، معايير الحدود، تصنيف الجيران، ومبادئ الدحض. التعارض يفتح مراجعة ولا يسوى تلقائيًا.
