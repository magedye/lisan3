# معيار الإغلاق التنفيذي في V2

## شرط `V2_STATIC_SELF_TESTS_PASS`
يجب أن تنجح اختبارات إنشاء Schemas/OpenAPI، الاختبارات الموجبة والسالبة للعقود، تحقق السجلات والتتبع، fixture parity، Tanzil profile، وعقود البحث V2 بما فيها ترتيب `SemanticDerivationChain` وحاجز MOA consensus.

## شرط `READY_FOR_BLIND_IMPLEMENTATION`
يستطيع مطور جديد تنفيذ Phase 0 والنموذج الأول من V2 وحدها دون اتخاذ قرار منهجي/معماري غير موثق. `CAP-GO-01` لا يمنع البدء لأن Python fallback محدد، لكنه يمنع اعتبار Opal orchestrator حاكمًا حتى PASS.

## شرط المخرجات الدلالية
لا تعتبر النتيجة البحثية مكتملة لمجرد وجود خلاصة؛ يجب أن تطابق Artifact/Skill/Schema المناسب، وتظهر الطبقات والتتبع والبدائل والنقض والفجوات. `UNRESOLVED` مقبول متى كان مبررًا ومحددًا بشروط إعادة فتح.

## ما لا يثبته الإغلاق
لا يثبت أن المنتج منفذ، ولا أن Semantic Evals نجحت في Runtime، ولا أن الثقة معايرة، ولا أن أي مفهوم جذري صحيح.
