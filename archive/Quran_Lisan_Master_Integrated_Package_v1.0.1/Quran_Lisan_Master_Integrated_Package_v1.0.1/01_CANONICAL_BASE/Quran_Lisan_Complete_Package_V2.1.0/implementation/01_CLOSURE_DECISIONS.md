# قرارات الإغلاق التنفيذي المدمجة في V2

## القرارات الملزمة
1. **العقد أولاً:** Pydantic v2 هو المصدر التنفيذي لعقود البيانات في هذا الإصدار، وتولد منه JSON Schema وOpenAPI.
2. **P0 لا يعني دائمًا جدولاً:** نفرق بين `P0_CAPABILITY` (قدرة)، `P0_CONTRACT` (عقد)، و`P0_PERSISTENCE` (تخزين دائم).
3. **سجلات أول Prototype:** `StructuralAnnotation` تخزين P0؛ `LayerAttribution` و`FalsificationRun` عقود P0؛ `LexicalUnitHypothesis` تخصص من `Hypothesis`؛ `SemanticNeighborResult` عقد P0 للنموذج الأول.
4. **جذر الإثبات الأول:** `س ل م` (`PROTOTYPE-SLM-01`)؛ الجار الدلالي الاختباري: `ص ل ح`؛ الاختيار يختبر التنوع الصرفي، تعدد الفروع المحتمل، والحالات الصعبة، ولا يقرر معنى الجذر مسبقًا.
5. **QAC في Fixture فقط:** بيانات Quranic Arabic Corpus 0.4 المستخدمة هنا هي `STRUCTURAL_FIXTURE_ONLY` ولا تدخل كدليل دلالي داخلي ولا تصبح مصدر Runtime معتمدًا.
6. **لا عتبات سحرية:** لا أوزان/نسب ثقة نهائية قبل المعايرة. المخرجات الحالية تعرض المكونات والاكتمال والفجوات والفئات الوصفية.
7. **المصادر تفشل مغلقًا:** محاولة استخدام مصدر خارجي في `INTERNAL_ANALYSIS` ترفض تقنيًا، ولا تتحول إلى تحذير فقط.
8. **البيان النبوي:** يحسم وفق DR-020: مصدر مقارنة خارجي ذو أولوية خاصة ونطاق محدود بما يثبته النص المنقول؛ لا يدخل الاستقراء الداخلي تلقائيًا.
9. **CTL-028:** يصبح `ACCEPTED`؛ التشابه المتجهي/الرسم البياني مرشح اكتشاف فقط ولا يرقى إلى Evidence (دليل) أو Confidence (ثقة) بذاته.
10. **سجل واحد حاكم:** لا نسخ `FINAL_*` مكررة؛ Registries هذه الحزمة هي النسخ التنفيذية الوحيدة للإغلاق.
11. **QA الوثائق بيئي:** أي حكم بصري على DOCX يربط ببيئة التصيير، ولا يعتبر عدد الصفحات حقيقة ثابتة عبر جميع البرامج.
12. **Opal مشروط:** نتيجة `CAP-GO-01` لم تُنفذ في هذه الحزمة. عند عدم PASS لجميع اختبارات P0، المنسق الحاكم هو Python fallback (المحرك الاحتياطي بلغة بايثون).

## إضافات V2 الحاكمة
- شكل النتيجة البحثية وسلسلة اشتقاق الدلالة جزء من عقد التنفيذ، لا تفضيل عرضي.
- `SemanticBoundary` و`DecisiveContextAssessment` و`HypothesisOrigin` وامتدادات الدحض والجيران عقود رسمية.
- `RootResearchArtifact` و`TermResearchArtifact` و`VerseSemanticAnalysisArtifact` مخرجات بحثية منظمة؛ البطاقات مشتقة فقط.
- MOA وضع مراجعة اختياري ولا يصبح إجماع الوكلاء دليلًا.
