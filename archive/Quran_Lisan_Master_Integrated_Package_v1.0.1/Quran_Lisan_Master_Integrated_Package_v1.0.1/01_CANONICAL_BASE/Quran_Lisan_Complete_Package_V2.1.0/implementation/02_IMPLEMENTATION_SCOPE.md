# نطاق التنفيذ المغلق للنموذج الأول

## 1. الهدف
تمكين فريق جديد من بناء **نواة بحث لجذر واحد** دون اتخاذ قرار منهجي غير موثق.

## 2. داخل النطاق
- Python 3.12 كهدف Runtime (بيئة التشغيل).
- Pydantic v2 للعقود، SQLite+FTS5 للتخزين/الفهرسة، FastAPI لبوابة الأدوات.
- Tanzil Uthmani 1.1 / Hafs بوصفه ملف النص المرجعي بعد التحقق الحتمي.
- Fixture بنيوي محدود للجذر `س ل م`؛ مصدر بنيوي واسع يبقى خلف `GQ-001`.
- وكيل بحث رئيسي + وكيل معارض عند الحاجة.
- Skills من SK-01 إلى SK-13.
- Internal analysis (الاستقراء الداخلي) ثم snapshot مغلق ثم مقارنة خارجية اختيارية.
- Root concept (المفهوم الجذري)، local meaning (المعنى الموضعي)، competing hypotheses (فرضيات متنافسة)، neighbor comparison (مقارنة جار)، falsification (محاولة الدحض)، completeness (اكتمال البحث).

## 3. خارج النطاق
- ادعاء صحة دلالية مطلقة.
- ثقة رقمية معايرة.
- اعتماد QAC كمصدر إنتاجي.
- Vector/graph semantic authority.
- تعدد القراءات أو المستخدمين أو النشر.

## 4. شرط عدم التخمين
إذا واجه الفريق قرارًا غير مغطى بعقد أو Registry (سجل) أو Gate (بوابة)، يتوقف الجزء المتأثر ويُسجل `SPEC_GAP`؛ لا يختار المطور سياسة جديدة من نفسه.
