# سياسة إعادة التأهيل CAP-GO-01

نتيجة PASS صالحة فقط للبيئة المسجلة. تعاد الاختبارات عند: تغيير جوهري في Opal/Gem/Agent Mode، تغيير نوع الحساب/الصلاحيات، فقد/تغير export/receipt behavior، تغيير tool/structured-output semantics، أو بعد 90 يومًا قبل أي اعتماد إنتاجي جديد. إلى أن تعاد، الحالة `CAPABILITY_GATED` ويملك Python fallback التنسيق الحاكم.
