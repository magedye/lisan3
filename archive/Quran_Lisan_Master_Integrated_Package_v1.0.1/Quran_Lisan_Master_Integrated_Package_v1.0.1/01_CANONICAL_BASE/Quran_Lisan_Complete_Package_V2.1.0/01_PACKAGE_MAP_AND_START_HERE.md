## الخريطة الموديولية
- `reference/`: الهدف، المنهج، المصطلحات، مقدمة اعتماد AI، دستور حوكمة AI، المعمارية والمتطلبات.
- `implementation/`: إغلاق التنفيذ والتوافق والمصادر والقبول.
- `research/`: طريقة البحث العميق، القالب النهائي، الحدود الدلالية، MOA والمقارنة.
- `contracts/`: Pydantic/JSON Schema/OpenAPI والعقود الحتمية.
- `skills/`: كيف تنفذ المهمات الحساسة.
- `registries/`: المتطلبات والضوابط والقرارات والمصطلحات والحالات.
- `acceptance/`: الاختبارات ومصفوفة Requirement→Test→Evidence→Acceptance.
- `prototype/`: Fixture النموذج الأول.
- `sources/`: ملفات هوية المصادر وبيانات التقييم.
- `cap-go-01/`: اختبار قدرة Gem/Opal.
- `inputs/`: مدخلات المالك والمادة البحثية المرجعية غير الحاكمة.
- `history/`: أثر الإصدارات والمصالحة، غير حاكم.
- `release-evidence/`: أدلة إنشاء V2 وتحققها.

- `sources/AI_CAPABILITY_EVIDENCE_REGISTRY.csv`: أدلة خارجية لتبرير قدرات AI وحدود الاستدلال منها؛ ليست دليلًا دلاليًا قرآنيًا.
