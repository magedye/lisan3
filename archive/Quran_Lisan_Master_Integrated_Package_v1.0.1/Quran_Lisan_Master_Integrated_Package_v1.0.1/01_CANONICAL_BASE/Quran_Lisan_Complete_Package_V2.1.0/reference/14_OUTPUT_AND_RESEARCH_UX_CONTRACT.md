# عقد المخرجات وتجربة الباحث

**الإصدار المدمج في V2:** 2.1.0  
**الحالة:** `V2_FINAL_COMPREHENSIVE_BASELINE / READY_FOR_BLIND_IMPLEMENTATION`  
**التاريخ:** 2026-09-05

## 1. المخرج الرسمي
لا يعرض النظام فقرة حرة فقط. كل جواب دلالي يبنى أولًا كمخرج منظم، ثم يصاغ **البيان الدلالي** منه.

## 2. قالب البيان الدلالي
1. **السؤال ووحدة التحليل.**
2. **النتيجة:** المعنى المرجح / المفهوم الجذري / غير محسوم.
3. **درجة الثقة:** مع المكونات وحالة المعايرة.
4. **اكتمال البحث.**
5. **حالة التحقق المستقل.**
6. **أسباب الترجيح المختصرة.**
7. **أقوى الأدلة الداخلية.**
8. **أصعب المواضع والأمثلة المضادة.**
9. **الفرضيات البديلة.**
10. **السمة الفارقة/ما لم يحسم في الجيران.**
11. **ما الذي يمكن أن يغير النتيجة؟**
12. **نطاق النتيجة وملف النص/القراءة.**
13. **المقارنة الخارجية** — قسم منفصل لا يظهر إلا إذا نفذت.

## 3. الإفصاح التدريجي
المستخدم يرى ملخصًا واضحًا أولًا، ويمكنه فتح تفاصيل الأدلة، المواضع، المشتقات، الاختبارات، وسجل التنفيذ. لا يلزم عرض كل الطبقات الثلاثين في كل جواب.

## 4. لغة اليقين
- مسموح: «أرجح»، «الأدلة الحالية تدعم»، «غير محسوم»، «ثقة معايرة/غير معايرة».
- ممنوع دون دليل استثنائي ونطاق واضح: «هذا هو المعنى الحقيقي قطعًا»، «لا يحتمل غيره».
- لا يسمى المخرج الرسمي «تفسيرًا» أو «فقهًا» أو «كشفًا».

## 5. المقارنة الخارجية
تعرض دائمًا بصريًا ومنطقيًا منفصلة عن النتيجة الداخلية، مع نوع المصدر ومواطن الاتفاق والاختلاف، ولا تدمج في فقرة تجعل القارئ غير قادر على معرفة مصدر كل دعوى.

## 6. واجهة عربية أولًا
الواجهة الأساسية عربية واتجاهها من اليمين إلى اليسار، والمصطلحات الإنجليزية تظهر عند الحاجة التقنية مع شرح عربي أول ظهور لها.


## مدمج في V2 — عقد «لماذا رُجِّح هذا؟»
يجب أن يجيب البيان الدلالي دون كشف التفكير الداخلي الخاص: النتيجة، نطاقها، أقوى أسباب منظمة، الأدلة القابلة للفتح، البدائل، أقوى counterevidence، ما بقي غير محسوم، CompletenessProfile، نوع التحقق المستقل، وخطر المعرفة المسبقة/المصادر الخارجية. لا يستخدم نص reasoning مخفي أو سرد chain-of-thought كدليل.


## V2 — ترتيب البيان الدلالي الإلزامي
القالب السابق يبقى مبدأ العرض، ويضاف إليه عقد ترتيب المساهمات: دلالة الجذر → دلالة التصريف والاشتقاق العامة → دلالة المفردة وعلاقتها بالجذر → دلالة الصيغة العامة → دلالة التركيب العامة → تحقق الصيغة الخاص → تحقق التركيب والأدوار الخاص → مقتضى السياق والخطاب → المعنى الموضعي → البيان الدلالي النهائي. التفاصيل والعقود الآلية في `research/01_FINAL_RESULT_AND_SEMANTIC_DERIVATION_CONTRACT.md`.

### البحث الكامل والبطاقات
`RootResearchArtifact` و`TermResearchArtifact` هما المخرجان البحثيان المنظمان عند التأهيل الكامل. `RootCard` و`TermCard` نماذج عرض مشتقة فقط ولا تنشئ حقيقة جديدة.


## V2.1 — حالة الحكم المعروضة
عند عرض نتيجة بحثية يجب التمييز بين: `PROPOSED`, `RESEARCH_JUDGMENT`, `VERIFIED`، و`CANONICALLY_AUTHORIZED` عندما ينطبق الاعتماد. لا يجوز أن توحي واجهة العرض بأن `PREFERRED` داخل `SemanticDecision` يعني أن النتيجة أصبحت حقيقة رسمية للمشروع.
