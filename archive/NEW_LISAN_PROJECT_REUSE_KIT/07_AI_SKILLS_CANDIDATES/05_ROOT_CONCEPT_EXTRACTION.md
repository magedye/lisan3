# Candidate Skill: Root-Concept Extraction

**Classification:** `ADAPT`  
**Purpose:** Infer and, where warranted, prefer the minimum stable root contribution after layer controls, while permitting branches and unresolved results. Source: Semantic Skill §§3–12, 21–22. [TR-055]

**Inputs:** lexical-unit set; derivational/form/construction analyses; context clusters; neighbors; evidence/counterevidence; completeness.  
**Required context:** source profile, terminology revision, decision policy.  
**Allowed tools:** exact evidence resolver, coverage calculator, dependency/cycle checker.  
**Prohibited evidence:** model memory as Quran witness; retrieved similarity as proof; form/context effects silently promoted; external definitions in internal phase.

**Execution:** (1) verify inputs; (2) generate minimal candidates; (3) test layer survival; (4) compare branches and neighbors; (5) run rejection conditions; (6) select preferred/competing/unresolved; (7) state boundaries and reasons.  
**Required outputs:** preferred result or live alternatives; root/lexical scope; layer map; evidence relations; strongest counterevidence; unresolved cases; rejection condition/result; strength and completeness components.  
**Failure/uncertainty:** never force one concept; allow local meanings without a root concept.  
**Verification:** adversarial replay with hard occurrences, branch isolation, genericity and invented-distinction tests.  
**Dependencies:** Skills 02–04 and 07–11; result schema.
