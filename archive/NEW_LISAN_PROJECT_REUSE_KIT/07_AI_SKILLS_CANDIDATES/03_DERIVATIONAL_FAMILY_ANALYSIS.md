# Candidate Skill: Derivational-Family Analysis

**Classification:** `ADAPT`  
**Purpose:** Group related lexemes/forms without assuming one meaning or one root concept. Sources: Semantic Skill §§6, 12–13; legacy semantic-family map. [TR-053]

**Inputs:** occurrence inventory; root/lemma/form annotations; lexical-unit hypotheses.  
**Required context:** morphology source identity and ambiguity; derivation terminology.  
**Allowed tools:** deterministic morphology grouping; table/statistical summaries.  
**Prohibited evidence:** glosses as group labels; etymological unity assumed from spelling; letter semantics as proof.

**Execution:** (1) inventory derivations/forms; (2) separate inflection from derivation; (3) cluster structurally; (4) compare usage distributions; (5) propose lexical-unit/branch relations; (6) retain counterexamples.  
**Required outputs:** family members, structural relationships, distribution table, branch hypotheses, ambiguities, missing coverage.  
**Failure/uncertainty:** preserve unassigned forms and competing partitions.  
**Verification:** every member resolves to occurrences; no branch borrows evidence silently; tests include same-root different-unit and ambiguous-root cases.  
**Dependencies:** occurrence collection; morphology record; terminology.
