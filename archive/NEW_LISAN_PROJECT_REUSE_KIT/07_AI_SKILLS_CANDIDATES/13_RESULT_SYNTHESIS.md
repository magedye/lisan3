# Candidate Skill: Result Synthesis

**Classification:** `ADAPT`  
**Purpose:** Issue a concise preferred semantic conclusion or preserve competing/unresolved results with full reviewability. Sources: Semantic Skill §§20–22, 29–30; owner’s higher-AI-authority direction. [TR-063]

**Inputs:** validated artifacts from all applicable Skills; result-strength components; completeness; verification; external-influence log.  
**Required context:** terminology and output schema revisions.  
**Allowed tools:** evidence/dependency resolver; schema validator; citation verifier.  
**Prohibited evidence:** hidden unsupported claims; elegant prose as proof; fabricated execution; external support relabeled internal.

**Execution:** (1) reconcile alternatives; (2) decide preferred/competing/unresolved; (3) state scope and layer map; (4) summarize reasons and counterevidence; (5) report strength/completeness/verification separately; (6) validate citations and receipts; (7) create immutable revision.  
**Required outputs:** decision statement, alternatives, reasons, evidence/counterevidence, uncertainty, rejection condition, completeness, independent verification, provenance and revision lineage.  
**Failure/uncertainty:** omit unsupported root concept; retain local/structural findings; state missing evidence.  
**Verification:** every substantive sentence maps to an evidence/reason record; strength never increases because wording is confident.  
**Dependencies:** all applicable analysis Skills; final result schema.
