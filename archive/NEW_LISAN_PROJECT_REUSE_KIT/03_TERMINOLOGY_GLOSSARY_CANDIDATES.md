# Terminology Glossary Candidates

## Status and method

This is a candidate controlled language, not an adopted glossary. “Current Lisan3 meaning” comes from the active Semantic Skill, canonical contracts, current models, or clearly labeled legacy schemas. Recommended Arabic terms are agent proposals requiring owner and linguistic review. [TR-001]

| Term | Current Lisan3 meaning | Usefulness / ambiguity | Recommended Arabic candidate | Must not be confused with |
|---|---|---|---|---|
| Word | Not separately governed; often appears informally in occurrence/form discussions | Useful only for orthographic/token surface; highly ambiguous | **كلمة نصية** when a written token is intended | Lexeme, lexical unit, segment, root |
| Lexeme | `LEXEME` is an analysis unit: a usage-bearing lexical item rather than the root | Essential, but Lisan3 lacks a first-class model and Arabic definition | **وحدة معجمية** | Root, surface word, form, local meaning |
| Expression | `target_expression` is the literal target string and may be root/word/construction | Useful generic input label; too vague as a research unit | **تعبير مستهدف** | Lexical unit, construction, claim scope |
| Lexical unit | Implied by semantic branching and lexeme scope; not explicitly governed | Essential for polysemy/homonymy and branch identity | **وحدة معجمية** | Orthographic material, root, contextual sense |
| Root | Target identity for `ROOT_CORE`; not itself a semantic conclusion | Essential; must carry normalization/identity and possible ambiguity | **جذر صرفي مستهدف** | Root core, root concept, lexical unit |
| Root Core | Minimum positive, defensible stable structure after removing form/construction/context effects | Very high value; “core” can imply one unity before proof | **نواة دلالية جذرية مرشحة** until supported | Root, root definition, broad concept, common theme |
| Root Definition | Concise statement of an established root core within scope | Useful presentation layer; risks duplicating Root Meaning | **تعريف النواة الجذرية** | Evidence, explanation, root concept |
| Root Meaning | Explanation of the root’s semantic angle and center of gravity | Useful if distinct from definition; current schemas can make it repetitive | **دلالة الجذر المفسَّرة** | Root definition, local meaning |
| Root Concept | Wider conceptual model: participants, relation, state/change, invariant and variables | Central for the new project, but “concept” may overexpand beyond evidence | **المفهوم الجذري** or **النموذج التصوري للجذر** | Root core, local effects, encyclopedic concept |
| Material | Not operationally defined; Arabic “مادة” can mean root material or source content | Must be resolved early | **مادة جذرية** only for orthographic root family; otherwise avoid | Root concept, corpus material, source artifact |
| Meaning | Lisan3 distinguishes root meaning and local meaning, but generic “meaning” remains ambiguous | Never use unqualified in a schema | **معنى** only with qualifier: جذري/معجمي/موضعي | Signification, concept, interpretation |
| Signification / semantics | “Semantic” describes the analytical domain and contribution, not one field | Needed as a relation/property rather than a synonym for meaning | **دلالة** for an evidenced semantic contribution or tendency | Meaning instance, concept, confidence |
| Concept | `CONCEPT` is the broader cross-text conceptual analysis unit | Useful but scope must list included lexemes/relations | **مفهوم قرآني مركب** | Root concept, lexeme meaning |
| Form | Structural or morphological realization; the Skill asks what a form adds | Essential; distinguish observed label from semantic operator hypothesis | **صيغة صرفية** | Surface word, pattern, derivation, root contribution |
| Pattern | Appears with form/وزن; no current separate contract | Useful if it names a formal template | **وزن صرفي** | Form token, semantic operator, derivation |
| Inflection | Not separately modeled | Needed for person/number/gender/case/mood changes | **تصريف إعرابي/صرفي** as specified | Derivation, pattern meaning |
| Derivation | Mentioned in root/form coverage; not first-class | Needed to group related lexemes/forms without assuming same sense | **اشتقاق** | Inflection, root, lexical unit |
| Morphological operator | A proposed contribution attributable to a form; observation must remain separate from semantic claim | Very useful; operator claims need independent testing | **أثر صرفي مفترض/مثبت** | Form label, root meaning |
| Construction | `CONSTRUCTION` analysis unit for syntax/bound structure/preposition effects | Essential | **تركيب لغوي** with a typed subtype | Collocation, context, lexical unit |
| Syntax | Structural relation captured in observations | Useful as verifiable structure, not a semantic verdict | **بنية نحوية** | Construction meaning, participant role |
| Participant role | Agent/patient/affected entity etc.; used in clustering and differentiation | Essential to prevent participant properties entering the root | **دور مشارك** | Grammatical case alone, contextual judgment |
| Discourse | Included in local-meaning decomposition but not modeled | Needed for cross-sentence/referential/pragmatic effects | **بنية خطابية** | Immediate context, syntax |
| Context | Near textual/usage environment; a source of realization, not automatically root meaning | Essential but too broad unless typed | **سياق** with window/scope/type | Construction, discourse, evidence source |
| Local meaning | Meaning of a form at one Quranic location after layer interaction | Essential | **المعنى الموضعي** | Lexical meaning, root core, interpretation of the whole verse |
| Usage | Distributional instance/pattern across occurrences | Useful; distinguish an instance from an inferred rule | **استعمال** | Occurrence, evidence, meaning |
| Corpus | Admitted Quran text/structure used for internal analysis | Reuse concept; new project need not inherit Lisan admission status names | **المتن القرآني الموثَّق** | Dataset generally, external collection |
| Occurrence | Current `CorpusOccurrence` is a verse-level record; methodology expects target instances | Essential, but new model needs token/segment target locators | **موضع استعمال** | Verse record, evidence, citation |
| Observation | What text/data directly establishes before interpretation | Foundational | **ملاحظة قابلة للتحقق** | Interpretation, hypothesis, semantic claim |
| Interpretation | A possible reading of an observation | Foundational but absent from current persisted model | **تفسير تحليلي أولي** | Tafsir source, claim, observation |
| Hypothesis | Testable proposed explanation with scope, evidence refs, counterevidence and rejection condition | Reuse with richer revision lineage | **فرضية دلالية** | Preferred conclusion, evidence, confidence |
| Claim | Result that passed specified conditions within declared scope; in Lisan3 it is tied to lock/governance | Adapt for AI-issued semantic judgment | **دعوى دلالية معلَّلة** | Evidence, official truth, publication state |
| Preferred conclusion | Not current Lisan3 authority for AI; requested in new project | Missing and central | **استنتاج مرجَّح** | Established fact, root core identity, confidence |
| Evidence | Governed material supporting/challenging a claim; current implementation mainly stores refs | Essential; define admissibility and direction | **دليل** for a support relation backed by resolved source | Witness, clue, source, retrieved candidate |
| Witness | Not separately governed | Use for the quoted/located Quranic instance itself | **شاهد قرآني** | The inference drawn from it, external evidence |
| Clue | Not governed | Use for non-decisive suggestive feature | **قرينة** | Evidence sufficient for a conclusion, retrieval score |
| Counterevidence | Evidence that challenges, narrows, or rejects a hypothesis | Essential and first-class | **دليل معارض** | Unresolved case, alternative hypothesis |
| Source | Origin artifact/provider with an allowed role | Essential | **مصدر** | Reference/citation, evidence, authority |
| Reference | Locator or bibliographic pointer | Useful | **مرجع إحالة** | Source role, evidence itself |
| Source role | Allowed use of a source/field at a stage | Foundational | **دور المصدر** | Source identity, authority, trustworthiness |
| Authority | In Lisan3, power to define a contract/status/transition within scope | Mostly governance-specific; retain only for project configuration ownership | **سلطة القرار** | Evidential strength, source reliability |
| Internal induction | Corpus-first observation and hypothesis formation before external comparison | Central but must acknowledge pretrained-model risk | **استقراء قرآني داخلي** | Proof of cognitive isolation, statistical induction alone |
| Analysis | General process; Lisan3 decomposes it into stages | Too broad unless protocol/stage is named | **تحليل** plus method/stage | Observation, conclusion, tool execution |
| Preference / weighting | Not a Lisan3 AI authority action | Central new capability | **ترجيح دلالي** | Confidence, majority vote, publication approval |
| Falsification | Active attempt to find a specified disconfirming observation | Essential | **اختبار نقض** | Mere criticism, absence of support |
| Rejection condition | Observable condition and method that rejects/narrows/reopens a hypothesis | Essential | **شرط رفض/تضييق الفرضية** | Generic “if wrong” statement |
| Semantic neighbor | Candidate in a shared domain requiring explicit differentiation | Essential | **جار دلالي مرشح** | Synonym, vector neighbor, graph neighbor |
| Distinctive residue | Minimal positive difference surviving layer controls | Useful but Arabic needs owner validation | **البقية الفارقة** or **السمة الفارقة الدنيا** | Negative definition, context-only difference |
| Confidence | Skill warns against uncalibrated percentages; legacy/current fields are inconsistent | Must be redesigned | **قوة النتيجة** for evidence-backed strength; reserve **ثقة احتمالية** for calibrated probability | Completeness, verification, model self-confidence |
| Research completeness | Multidimensional coverage exists in method but not as a first-class current result | Central missing term | **اكتمال البحث** | Result strength, corpus size, number of tokens |
| Independent verification | Separate review evidence; same model/multiple agents do not guarantee it | Central | **تحقق مستقل** with declared independence class | Agreement, repetition, release approval |
| Provenance | Chain from result to evidence/source/run/method/tool/model revisions | Essential | **نَسَب الدليل والتنفيذ** or **سلسلة المنشأ** | Citation alone, authority, audit timestamp |
| Contamination | Actual prohibited influence/exposure; blocked access is not contamination | Essential | **تلوث مصدري/معرفي** with detected/suspected/unknown status | Source use that was allowed and declared |
| Freshness | Current/stale/invalidated in Lisan3 lifecycle | Useful only as dependency validity | **صلاحية الاعتماد الحالية** | Semantic strength, publication status |
| Review | Human/system assessment in Lisan3 | Useful only if actor/scope/criteria are recorded | **مراجعة** | Independent verification, acceptance |
| Publication | Public release axis | Not needed initially | **نشر** | Semantic conclusion, review, completeness |

## Missing terminology the new project should define

1. **هوية الوحدة المعجمية:** stable identifier for a hypothesized lexical unit, distinct from root and surface form. [TR-002]
2. **إسناد المساهمة الدلالية:** explicit assignment of a feature to root, lexeme, form, construction, participant roles, discourse, or context. [TR-003]
3. **نوع الاستقلال:** human-independent, model-family-independent, context-blind, data-independent, or merely repeated. [TR-004]
4. **درجة اكتمال البحث:** a vector of coverage dimensions, never a synonym for conclusion strength. [TR-005]
5. **سجل التأثير الخارجي:** what external source was opened, when, for what role, and which result revision changed. [TR-006]
6. **مستوى التعرض القبلي للنموذج:** declared/unknown/assessed exposure of model training to tafsir, dictionaries, and Islamic QA. [TR-007]
7. **قرار دلالي صادر عن الذكاء الاصطناعي:** preferred conclusion plus scope, support, alternatives, counterevidence, uncertainty, completeness and verification—not “truth.” [TR-008]
8. **مسافة دلالية متعددة الأبعاد:** comparison vector by event, participants, direction, aspect, construction, distribution, etc., distinct from embedding distance. [TR-009]
9. **حالة غير محسومة:** unresolved because of evidence conflict, insufficient structure, lexical ambiguity, or incomplete search; reason must be typed. [TR-010]
10. **دليل أولي / دليل مشتق / مرشح استرجاع:** primary Quran text/structure, internally derived observation, and discovery candidate must be separate nouns. [TR-011]

## Recommendation

Adopt no field name until the owner approves a compact terminology charter containing Arabic term, English key, definition, positive/negative examples, forbidden synonym collisions, and versioning/migration rules. Do this before schemas and prompts, because retrofitting terminology across prompts, JSON, database fields, evaluations and UI is expensive. [TR-012]
