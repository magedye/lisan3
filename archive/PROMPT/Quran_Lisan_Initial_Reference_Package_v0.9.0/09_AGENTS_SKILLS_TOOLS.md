# الوكلاء والمهارات والأدوات

## 1. التعريف الثلاثي
- **المهارة (AI Skill):** بروتوكول يحدد **كيف** تنفذ مهمة منهجية محددة.
- **الوكيل (AI Agent):** كيان يدير الهدف ويحدد **ماذا** ينفذ و**متى** وبأي ترتيب ضمن الصلاحيات.
- **الأداة (Tool):** تنفيذ فعلي قابل للتحقق لجلب بيانات أو حساب أو تحقق.

القاعدة: حرية الوكيل في اختيار المسار لا تمنحه حق تغيير منهج المهارة الحساسة، والمهارة لا تدعي أن أداة نفذت ما لم يوجد سجل تنفيذ.

## 2. استراتيجية الوكلاء
الافتراضي هو **وكيل بحث رئيسي واحد** يستخدم المهارات. يستدعى وكلاء إضافيون عندما تحقق وظيفة استقلالًا حقيقيًا أو فصل سياق أو مراجعة متخصصة. لا ننشئ شبكة وكلاء لمجرد التقسيم الشكلي.

### وكلاء مقترحون
- `AG-01 Research Orchestrator` — وكيل البحث والمنسق.
- `AG-02 Adversarial Verifier` — وكيل نقض/معارضة عند الحاجة.
- `AG-03 Heritage Leakage Reviewer` — مراجع تسرب المصادر والادعاءات غير المتتبعة.
- `AG-04 Blind Independent Verifier` — تحقق أعمى عند المشغلات.
- `AG-05 Output & Terminology Reviewer` — جودة البيان والمصطلحات؛ لا يغير الحكم الدلالي بذاته.

## 3. المهارات الأساسية
- `SK-01` تشخيص وحدة التحليل.
- `SK-02` جمع المواضع ومدى البحث.
- `SK-03` تحليل المادة والاشتقاق والتصريف.
- `SK-04` تحليل الصيغة والوزن.
- `SK-05` تحليل التركيب والأدوار.
- `SK-06` استخراج المفهوم الجذري.
- `SK-07` تحليل المعنى الموضعي.
- `SK-08` بناء الفرضيات المتنافسة.
- `SK-09` مقارنة الجيران والسمة الفارقة.
- `SK-10` اختبار النقض والحالات الصعبة.
- `SK-11` الترجيح الدلالي.
- `SK-12` المقارنة الخارجية المؤجلة.
- `SK-13` بناء البيان الدلالي.

كل مهارة يجب أن تحدد: الهدف، المدخلات، السياق المسموح، الأدوات، الخطوات، المخرجات، حالات الفشل، شرط التوقف، والتحقق.

## 4. أدوات حتمية مرشحة
- `get_occurrences(target, text_profile)`
- `get_verse(verse_id, text_profile)`
- `get_context(verse_id, window_policy)`
- `get_morphology(occurrence_id)`
- `get_derivational_family(root_id)`
- `get_syntactic_relations(occurrence_id)`
- `get_collocations(target, scope)`
- `calculate_research_completeness(run_id)`
- `validate_evidence_refs(run_id)`
- `record_tool_execution(...)`
- `apply_source_policy(source_id, phase)`
- `calculate_confidence_components(run_id, calibration_version)`
- `retrieve_external_sources(...)` — محظورة قبل بوابة المقارنة الخارجية.

لا تعني الأسماء اعتماد لغة برمجة أو API بعينها.

## 5. بوابة اختيار المهارة
تستخدم خريطة تشخيص موضوعية، مثال:
- «معنى لفظة في آية» → معنى موضعي.
- «ما أصل/مفهوم هذا الجذر؟» → مفهوم جذري.
- «ما أثر أفعل؟» → صيغة/وزن.
- «ما الفرق بين جاء وأتى؟» → مقارنة دلالية.

إذا كان الطلب متعدد الوحدات، يحدد المنسق وحدة أساسية ووحدات تابعة، ولا يخلط النتائج في حقل واحد.

## 6. الاستقلال الحقيقي
موافقة وكيلين يستخدمان نفس النموذج والسياق ليست دليلًا مستقلًا. الاستقلال يقوى بفصل السياق، عدم كشف النتيجة السابقة، استخدام أدوات تحقق حتمية، أو نموذج/جلسة أخرى بحسب الحاجة.
