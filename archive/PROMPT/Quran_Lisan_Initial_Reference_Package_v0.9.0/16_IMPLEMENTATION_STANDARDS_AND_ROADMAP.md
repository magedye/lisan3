# معايير التنفيذ وخارطة الطريق

## 1. معايير هندسية عامة
1. المنهج والمصطلحات والعقود ملفات إصدارية مستقلة عن مزود الذكاء.
2. الأدوات الحتمية لا تعيد تفسير السؤال؛ تنفذ عقدًا ضيقًا وتعيد بيانات موثقة.
3. Routes/واجهات النقل — أيًا كانت التقنية — لا تحتوي منطق الدلالة الحاكم.
4. لا dependency جديدة دون حاجة مثبتة ودور محدد.
5. لا fallback صامت من مصدر مفقود إلى ذاكرة النموذج.
6. كل استدعاء نموذج يسجل المزود والإصدار والمهارة والسياق المسموح وأدواته.
7. لا تخزن سلسلة التفكير الداخلية الخاصة؛ خزن الملاحظات والفرضيات والأدلة والاختبارات والأسباب المنظمة القابلة للمراجعة.
8. كل تعديل منهجي مهم يحمل إصدارًا وسجل أثر.
9. لا تستخدم vector/graph score كـ confidence score.
10. كل اختيار منصة في v0.9 يبقى قابلًا للاستبدال حتى المصالحة مع حزمة إعادة الاستخدام.

## 2. مراحل التنفيذ
### المرحلة 0 — تثبيت المرجع
- اعتماد هذه الحزمة.
- استقبال `NEW_LISAN_PROJECT_REUSE_KIT` والمصالحة.
- إصدار v1.0 النهائي.

**الخروج:** لا open questions تمنع نواة البيانات والمنهج.

### المرحلة 1 — النواة الحتمية
- ملف النص المعتمد.
- مخزن المواضع.
- أدوات الاسترجاع الدقيقة.
- طبقة البيانات الصرفية/التركيبية المعتمدة.
- Source Policy + Evidence Ledger.

**الخروج:** يمكن حساب المجال والمواضع والتحقق من المراجع دون نموذج لغوي.

### المرحلة 2 — المهارات والوكيل الأساسي
- تنفيذ Skills الأساسية.
- مزود نموذج واحد خلف واجهة تجريد.
- مخرجات منظمة.
- دراسات حالة جذر/معنى موضعي.

**الخروج:** مسار كامل داخلي يمكن تتبعه، مع score غير معاير عند الحاجة.

### المرحلة 3 — التنسيق المتقدم Gem/Opal أو البديل
- Orchestration متفرع.
- وكيل الدحض.
- مراجع التسرب.
- التحقق المستقل المشروط.

**الخروج:** إثبات أن تعدد المسارات يضيف قيمة قابلة للقياس ولا يكرر نفس النموذج شكليًا.

### المرحلة 4 — الثقة والمقارنة الخارجية
- benchmark ومعايرة confidence.
- External Comparison layer.
- إعادة الفتح وإدارة الإصدارات.

**الخروج:** نسب ثقة ذات نسخة معايرة واختبارات calibration.

### المرحلة 5 — المنتج والذاكرة والتوسع
- واجهة بحث متكاملة.
- ذاكرة بحث منضبطة.
- optional graph/vector discovery.
- مزودون متعددون أو نموذج محلي إذا أثبتت الحاجة.

## 3. ممنوعات الطريق
- القفز إلى نظام Multi-Agent ضخم قبل إثبات مهارات وأدوات النواة.
- بناء أنطولوجيا دلالية كبيرة قبل وجود عقود الأدلة.
- hard-code للأوزان والعتبات من إجابات النقاش.
- ربط المشروع تقنيًا بـGem/Opal بحيث تضيع المنهجية إذا تغيرت المنصة.
- إعادة إنشاء حوكمة Lisan3 الثقيلة دون دليل حاجة.
