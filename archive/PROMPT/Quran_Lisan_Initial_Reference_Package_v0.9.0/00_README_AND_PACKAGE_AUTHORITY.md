# الحزمة الوثائقية المرجعية الأولية — مشروع لسان القرآن الجديد

**الإصدار:** 0.9.0  
**التاريخ:** 2026-09-05  
**الحالة:** `INITIAL_REFERENCE_BASELINE / PENDING_REUSE_KIT_RECONCILIATION`

## 1. وظيفة الحزمة
هذه الحزمة هي **مصدر الحقيقة الوحيد الحالي** للمشروع الجديد؛ والمقصود بذلك أن فريق التصميم أو التطوير أو الاختبار يرجع إليها أولًا، ولا يستعمل المحادثات السابقة أو إجابات الوكلاء أو ملفات النقاش بوصفها متطلبات تنفيذية مباشرة بعد صدور هذه الحزمة.

الحزمة **أولية وليست نهائية**: أعدت عمدًا لتستوعب في الخطوة التالية مخرجات `NEW_LISAN_PROJECT_REUSE_KIT`. عند وصول تلك الحزمة تتم مصالحة رسمية ثم يصدر `Final Release Package` بإصدار رئيسي جديد.

## 2. قاعدة عدم التخمين
- إذا حددت الحزمة حكمًا: يجب اتباعه.
- إذا وسمت حكمًا `PROVISIONAL`: يجوز التصميم حوله دون إقفال خيار يصعب الرجوع عنه.
- إذا وسمت بندًا `PENDING_RECONCILIATION` أو `OPEN_QUESTION`: **لا يجوز لفريق التنفيذ اختراع قرار**؛ يسجل blocker ويعود إلى سجل القرارات.
- الأمثلة العددية الواردة في مواد المصدر لا تتحول إلى عتبات إنتاجية إلا إذا ظهرت في `registries/CONTROL_REGISTRY.csv` بحالة معتمدة.

## 3. ترتيب السلطة داخل المشروع الجديد
1. أحدث توجيه صريح من المالك.
2. هذه الحزمة المرجعية وإصداراتها اللاحقة.
3. السجلات الآلية داخل `registries/`.
4. قرارات معمارية/منهجية معتمدة لاحقًا.
5. التنفيذ والاختبارات بقدر ما يثبتانه فقط.
6. `NEW_LISAN_PROJECT_REUSE_KIT` بعد وصولها **مرجع إدخال للمصالحة** وليست سلطة تلقائية.
7. ملفات النقاش الحالية وإجابات الوكلاء مواد تاريخية/استشارية بعد صدور هذه الحزمة.

## 4. ألفاظ الإلزام
- **يجب**: متطلب إلزامي.
- **يمنع**: حظر إلزامي.
- **ينبغي**: توصية قوية يجوز تجاوزها بسبب موثق.
- **يجوز**: خيار مسموح.
- **معلق**: يحتاج قرارًا ولا يجوز التخمين فيه.

## 5. حالات البنود
- `BASELINE_ACCEPTED`: معتمد في هذه النسخة.
- `PROVISIONAL`: اختيار مستهدف مبدئي قابل للتغيير بعد المصالحة.
- `EXPERIMENTAL`: فكرة للاختبار لا يجوز البناء عليها كحقيقة.
- `PENDING_RECONCILIATION`: ينتظر حزمة Lisan3 أو قرارًا لاحقًا.
- `DEFERRED`: مؤجل وليس ضمن نطاق المرحلة الأولى.
