# نموذج التحليل الدلالي وطبقاته

## 1. وحدات التحليل
يجب تحديد وحدة واحدة أساسية لكل تشغيل، ويمكن استدعاء وحدات مساندة:
- مفهوم جذري.
- مفردة/وحدة معجمية.
- صيغة أو وزن.
- تركيب.
- معنى موضعي.
- آية/مقطع.
- مفهوم قرآني أوسع.
- مقارنة بين جيران دلاليين.

## 2. المعادلة التحليلية
المعنى الموضعي **ليس** معنى الجذر وحده. يستخدم النظام هذا النموذج التفسيري:

`المعنى الموضعي = مساهمة الجذر + أثر الصيغة/الاشتقاق + أثر التركيب + أدوار المشاركين + أثر السياق والخطاب`

هذه صيغة تحليلية وليست معادلة حسابية؛ وقد تكون بعض المساهمات غير مستقلة في موضع بعينه.

## 3. المراحل التشغيلية الست
1. **سلامة المادة:** النص، الهوية، القراءة/الرواية، الرسم، حدود الموضع.
2. **البنية اللفظية والصرفية:** الجذر، الوزن، الصيغة، التصريف، الاشتقاق.
3. **البنية التركيبية والعلاقات:** الأدوات، الإسناد، الفاعل والمفعول، الإحالة، الأدوار الدلالية.
4. **الاستقراء الدلالي:** التوزيع، المصاحبات، السياق، المواضع النظيرة، التقابلات، تكرار الأحداث، بنية الخطاب.
5. **المنافسة والنقض:** الفرضيات، البدائل، الجيران، الحالات الصعبة، الأمثلة المضادة، اختبار النقض.
6. **الحكم والبيان:** الترجيح، الثقة، الاكتمال، التحقق المستقل، سجل الأدلة، البيان الدلالي.

## 5. مداخل اكتشاف المعنى
- المشترك بين جميع المواضع.
- شبكة الاشتقاقات.
- طرح أثر الصيغة.
- التراكيب والمصاحبات.
- الأدوار الدلالية.
- الحالة قبل الحدث وبعده.
- المقارنة بالجيران.
- المقابلات والأضداد مع الحذر من مساواة الضد السياقي باللغوي.
- الحالات الصعبة.
- الاستبعاد بين الفرضيات.
- اختبار تنبؤي على مواضع لم تستخدم في بناء الفرضية عندما تسمح البيانات.
- الاقتصاد التفسيري: أقل بنية تفسر أكبر قدر بلا تكلف.

## 6. أفكار تجريبية لا تعد قواعد
اختبار الإبدال، التحليل التوزيعي المتجهي، تحليل الشحنة الوجدانية، إعادة الصياغة لكشف التسرب، وحظر كلمات بعينها: يمكن تقييمها لاحقًا، لكنها لا تعد حاليًا دليلًا أو ضمانًا منهجيًا.
