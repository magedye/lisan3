# البنية المنطقية المستهدفة

## 1. القرار المعماري الأولي
البنية المستهدفة **هجينة**: الذكاء الاصطناعي مسؤول عن التحليل والاستنباط والترجيح، بينما توجد طبقة مستقلة حتمية لمسؤوليات المصدر والهوية والاسترجاع والتحقق والحساب. استخدام Gem وOpal مستهدف مبدئيًا، لكن المنهج والعقود لا يعتمدون عليهما بحيث يمكن استبدالهما.

## 2. الرسم المنطقي
```text
الباحث / الواجهة
        │
        ▼
واجهة الحوار (Gem أو عميل آخر)
        │
        ▼
منسق البحث ومسار العمل (Opal أو Orchestrator بديل)
        │
  ┌─────┼─────────────────────┐
  │     │                     │
  ▼     ▼                     ▼
المهارات المنهجية       وكلاء تحقق مشروطون
  │                           │
  └──────────┬────────────────┘
             ▼
      بوابة الأدوات Tool Gateway
             │
  ┌──────────┼───────────────┐
  ▼          ▼               ▼
مدونة القرآن  بيانات بنيوية   سجل الأدلة/الحساب
  │          │               │
  └──────────┼───────────────┘
             ▼
     المحرك الدلالي المستقل
   (تحقق، هوية، حالات، قياس)
             │
             ▼
       سجل Research Run
             │
             ▼
       البيان الدلالي
```

## 3. المكونات المنطقية الإلزامية
1. **مرجع المنهج والمصطلحات** — ملفات/سجلات إصدارية مستقلة عن المزود.
2. **مدونة القرآن** — النص المعتمد وهوية المواضع.
3. **طبقة البيانات البنيوية** — صرف/نحو/علاقات مع مصدر وحالة.
4. **بوابة الأدوات** — عمليات حقيقية محددة الصلاحية.
5. **سجل المهارات** — بروتوكولات كيف تنفذ المهام الحساسة.
6. **منسق البحث** — يحدد ماذا ينفذ ومتى وفق تشخيص السؤال والحالة.
7. **وقت تشغيل النموذج** — مزود أو أكثر عبر واجهة قابلة للاستبدال.
8. **سجل الأدلة** — داعم/معارض/غير محسوم مع المصدر.
9. **محرك المفهوم الجذري** — عقد متخصص لاستخراج واختبار المفهوم.
10. **محرك المعنى الموضعي** — فصل الطبقات ثم تركيب الحكم الموضعي.
11. **محرك الفروق الدلالية** — الجيران والسمة الفارقة وعدم الحسم.
12. **محرك النقض** — حالات مضادة وشروط رفض/إعادة فتح.
13. **محرك الثقة والاكتمال** — مستقل عن نص النموذج.
14. **التحقق المستقل** — مشروط/اختياري حسب السياسات.
15. **طبقة المقارنة الخارجية** — محجوبة عن الاستقراء الداخلي.
16. **الذاكرة** — مفصولة حسب النوع والدور.
17. **سجل التشغيل والإصدارات** — لإعادة الفحص والانحدار.
18. **طبقة العرض** — البيان الدلالي وواجهة البحث.
19. **منظومة الاختبارات والتقييمات**.

## 4. ما هو مؤقت في v0.9
- Gem كواجهة حوارية: `PROVISIONAL`.
- Opal كمنسق مرئي/وكيل: `PROVISIONAL`.
- التقنية البرمجية للمحرك وقاعدة البيانات: `PENDING_RECONCILIATION`.
- قاعدة متجهية/رسم دلالي: `DEFERRED/OPTIONAL` ولا تصبح سلطة.
- أنطولوجيا دلالية كاملة: ليست شرطًا للبدء، وأي إضافة لاحقة تبدأ كطبقة مشتقة للاكتشاف.

## 5. مبدأ منع الارتباط بالمزود
لا توضع التعريفات والقواعد والعقود الوحيدة داخل Gem أو Opal. يجب أن تكون في ملفات/سجلات المشروع ثم تترجم إلى تعليمات كل مزود. تغيير النموذج لا يغير المنهج تلقائيًا.
