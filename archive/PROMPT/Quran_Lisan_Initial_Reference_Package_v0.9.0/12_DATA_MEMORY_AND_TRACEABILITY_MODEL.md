# نموذج البيانات والذاكرة وقابلية التتبع

## 1. الكيانات المنطقية الأساسية
- `TextProfile` — ملف النص والقراءة/الرواية والإصدار والهاش.
- `Verse` — آية بهوية ثابتة داخل الملف.
- `Occurrence` — موضع لفظي مستهدف.
- `StructuralAnnotation` — تحليل صرفي/نحوي مع مصدر وحالة.
- `SourceRecord` — هوية المصدر ونوعه والدور المسموح.
- `Observation` — ملاحظة قابلة للتتبع.
- `Hypothesis` — فرضية مع نطاق وشروط دحض.
- `EvidenceRef` — دليل مؤيد/معارض/محايد مرتبط بمصدر.
- `RootConceptResult` — المفهوم الجذري المنظم.
- `LocalMeaningResult` — معنى موضعي.
- `SemanticDifferenceResult` — نتيجة مقارنة جيران.
- `ResearchRun` — تشغيل بحث واحد بإصداراته وحالته.
- `ToolExecutionRecord` — سجل تنفيذ حقيقي لأداة.
- `AIExecutionRecord` — مزود/نموذج/مهارة/سياق الأدلة/المخرجات المنظمة، دون حفظ التفكير الداخلي الخاص.
- `ConfidenceReport` — مكونات الثقة وإصدار المعايرة.
- `VerificationReport` — تحقق مستقل أو حتمي.
- `ExternalComparisonRecord` — مقارنة لاحقة لا تختلط بالنتيجة الداخلية الأصلية.

## 2. طبقات الذاكرة
1. **تفضيلات المستخدم:** لغة العرض، مستوى التفصيل، إلخ.
2. **تاريخ البحث:** ما تم تشغيله ونتائجه.
3. **فرضيات مؤقتة:** لا تستخدم كدليل.
4. **نتائج مرجحة مع روابط أدلتها:** يمكن إعادة استخدامها كفرضيات تشغيلية فقط حتى إعادة التتبع.
5. **مواد خارجية:** مفصولة وممنوعة من الدخول إلى سياق الاستقراء الداخلي إلا بعد بوابة واضحة.

## 3. حالات ResearchRun المقترحة
`CREATED → ANALYSIS_UNIT_RESOLVED → INTERNAL_DATA_READY → OBSERVATIONS_READY → HYPOTHESES_READY → FALSIFICATION_COMPLETED → JUDGMENT_READY → INTERNAL_RESULT_CLOSED → [INDEPENDENT_VERIFIED] → [EXTERNAL_COMPARED] → PRESENTED`

العودة إلى مرحلة سابقة مسموحة مع تسجيل السبب؛ لا يجوز تجاوز مرحلة إلزامية دون أثر.

## 4. سلسلة التتبع
كل نتيجة مهمة يجب أن تسمح بالرجوع إلى:
`الحكم → الفرضيات → نتائج الاختبارات → الملاحظات → المواضع/البيانات → المصدر → إصدار المنهج/الأداة/النموذج`.

## 5. التغيير وإبطال النتائج
إذا تغير تعريف حاكم، مصدر النص، بيانات بنيوية جوهرية، مهارة تؤثر في الاستنتاج، أو نموذج الثقة، يجب تحديد النتائج المتأثرة وإعادة تقييمها أو وسمها بأنها تحتاج تحديثًا. لا تعاد كتابة النتائج التاريخية صامتًا.
