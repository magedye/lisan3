# حوكمة وضبط سلوك الذكاء الاصطناعي

## 1. التوجيه والإنفاذ
- **التوجيه:** إخبار النموذج بما يجب فعله.
- **الإنفاذ:** جعل المخالفة غير ممكنة تقنيًا أو قابلة للكشف والرفض.

القاعدة: **ما نحتاج ضمانه لا نتركه للتعليمات وحدها إذا أمكن إنفاذه أو التحقق منه.**

## 2. أنواع الضوابط
- غاية.
- تعريف.
- مبدأ أعلى.
- سياسة.
- قاعدة.
- قيد/حد.
- شرط.
- مانع.
- بوابة.
- إجراء.
- اختبار/تحقق.
- استثناء.
- معيار تقييم.
- وزن/عتبة معايرة.
- توصية/تفضيل.

هذه الأنواع ليست مرادفات. لا نستخدم «مانع» لشيء تأثيره مجرد خفض ثقة، ولا «معيار» لشيء ثنائي إلزامي.

## 3. بيانات كل ضابط
كل ضابط يجب أن يحمل: المعرف، الاسم، النوع، الرتبة، النطاق، درجة الإلزام، جهة الإنفاذ، أثر المخالفة، الحالة، السبب، والإصدار.

## 4. درجات أثر المخالفة
1. `INFO` — ملاحظة لا تغير النتيجة.
2. `WARN` — تحذير ظاهر.
3. `PENALIZE` — يخفض مكونًا مناسبًا أو يمنع رفع الحالة.
4. `REANALYZE` — يعيد الجزء المتأثر.
5. `BLOCK_RESULT` — يمنع النتيجة المطلوبة ويحول إلى حالة أضعف/غير محسوم.
6. `HALT_PATH` — يوقف المسار لأن مصدرًا أو شرطًا حاسمًا مفقود.

لا يُخفض **الثقة الدلالية** بسبب خطأ تنسيق أو لفظ اصطلاحي محض؛ يعالج في جودة المخرج. يجب أن يكون كل penalty مرتبطًا بعامل معرفي ذي صلة.

## 5. طبقات التحكم
- المدخلات والسياق.
- الأدوات والصلاحيات.
- تعليمات النظام والمنهج.
- المهارات.
- تنسيق الوكلاء ومسار العمل.
- المخرجات المنظمة.
- التحقق الحتمي.
- المراجعة المستقلة.
- الثقة والاكتمال.
- التقييمات والانحدار.
