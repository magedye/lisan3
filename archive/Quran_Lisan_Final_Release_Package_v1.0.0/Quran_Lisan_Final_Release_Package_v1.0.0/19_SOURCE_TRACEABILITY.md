# تتبع المصادر وحسم التعارضات

## 1. المصادر المستخدمة
- `وثيقة شاملة عن منهجية اللسان(1).md`: المصدر الأوسع للحجج المنهجية، 28 مادة دستورية، و30 طبقة تحليل.
- `اهم التحسينات.docx`: مراجعة قيود Lisan3 وما يحتفظ به/يخفف في المشروع الجديد.
- `لضمان عدم التاثر بالتراث.docx`: العزل الداخلي، فصل الدليل عن المعرفة السابقة، المقارنة الخارجية المؤجلة.
- `مرادفات التحكم.docx`: تصنيف الغايات والمبادئ والسياسات والقواعد والشروط والموانع والإجراءات والمعايير.
- `طبقات التحكم.docx` و`مهم خيارات وادوات التحكم.docx`: طبقات التحكم، التوجيه مقابل الإنفاذ، السياق، الأدوات، المخرجات، التحقق.
- `مصادر الاستنتاج.docx`: مصادر ومداخل وطرق استخراج المفهوم الجذري.
- `المصطلحات.docx`: معجم المصطلحات والتمييز بين مفردة/لفظة/موضع ومعنى/دلالة/مفهوم.
- `وظيفة المشروع.docx`: التمييز بين العملية والنتيجة والعرض، ومناقشة «تفسير/فهم/تدبر/كشف».
- `مواصفات الجذر.docx`: خصائص المفهوم الجذري وموانعه واختباراته ومخرجاته.
- `الهيكل.docx`: الفصل بين Agent/Skill/Tool وبوابة اختيار المهارة.
- `مقترحات اضافية.docx`: وكلاء تحقق قابلون للتوسع، مراجع تسرب، مراجع صياغة، وتصنيف القواعد.
- `خيارات التنفيذ.docx`: مقارنة Gem/Opal، النظام المستقل، RAG، الوكلاء، الأنطولوجيا، والنظام الهجين.
- `Synonyms Dataset(1).xlsx`: بيانات تجريبية لتفاوت القرب الدلالي بين مرشحين؛ ليست مصدرًا قرآنيًا.

## 2. تعارضات جرى حسمها في v0.9
### أ. «مفردة» أم «كلمة» أم «لفظة»؟
اعتمدنا: مفردة = وحدة معجمية؛ لفظة = شكل متحقق؛ موضع = ورود محدد؛ كلمة = شرح عام غير تقني.

### ب. «المفهوم الجذري» أم «النواة الدلالية»؟
اعتمدنا المفهوم الجذري ككيان نتيجة منظم، والنواة الدلالية للجذر كمحتواه الدلالي المركزي.

### ج. اسم المنتج
اعتمدنا العملية «التحليل الدلالي الاستقرائي»، النتيجة «المعنى المرجح»، والعرض «البيان الدلالي». لا نستخدم «تفسير» أو «فقه» أو «كشف» اسمًا رسميًا.

### د. صلاحية AI
نقلنا AI من «مقترح فقط» إلى «باحث ومرجح يحق له إصدار الحكم المرجح»، مع إبقاء المصدر والحساب والتحقق تحت عقود قابلة للإنفاذ.

### هـ. الأرقام والعتبات
لم نعتمد أي وزن أو threshold ورد كأمثلة في إجابات الوكلاء. جميعها تحتاج benchmark ومعايرة.

### و. الترادف
لا نفترض التطابق التام ابتداءً، لكن لا نعتبر اختلاف الشكل إثباتًا تلقائيًا لفارق محدد. البحث عن الفرق إلزامي؛ اختراع الفرق ممنوع؛ «غير محسوم» مسموح.

### ز. المختبر الأعمى
أداة تحقق متقدمة مشروطة، لا إجراء دائم لكل سؤال.

### ح. الأنطولوجيا والنواقل
جعلناها optional discovery layers، لا متطلبات أساسية ولا مصادر سلطة في v0.9.

## 3. مواد لم تعتمد كقواعد رغم ورودها في المصادر
- حظر أسماء مفسرين باستخدام logit bias بوصفه ضمانًا للنقاء.
- اختبار إعادة الصياغة كدليل كافٍ على التسرب/عدم التسرب.
- Temperature ثابت مثل 0.1/0.2 لكل المهام.
- ثلاثة بدائل إلزامية لكل سؤال.
- تغطية 85/90% كحد ثابت.
- ثقة 70/85/90% كحالات نهائية قبل المعايرة.
- إلزام Chain-of-Thought ظاهر؛ بدله نعتمد مخرجات استدلال منظمة قابلة للمراجعة دون مطالبة بحفظ أو كشف التفكير الداخلي الخاص للنموذج.

## 4. وضع المصادر بعد صدور الحزمة
المصادر المذكورة أعلاه تصبح **أثرًا تاريخيًا واستشاريًا**؛ التنفيذ يرجع إلى هذه الحزمة. عند تعارض أي مصدر تاريخي مع هذا الإصدار، تحكم حزمة v1.0.0 حتى إصدار تغيير رسمي لاحق.
