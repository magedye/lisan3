## متطلبات غير وظيفية إضافية v1.0
- **Reproducibility:** كل تشغيل يحمل hashes/revisions للنص والمنهج والـSkills والإعدادات والأدوات.
- **Idempotency:** retry لنفس العملية الحتمية لا ينشئ قرارًا دلاليًا مكررًا دون lineage.
- **Fail-closed source control:** غياب مصدر/صلاحية/هوية لا يسبب fallback إلى ذاكرة النموذج.
- **Unknown-field rejection:** العقود الحاكمة ترفض حقولًا غير معلنة.
- **Audit without hidden reasoning:** لا نخزن private chain-of-thought؛ نخزن reasons/evidence/tests المنظمة.
- **Exportability:** لا تعتبر Gem/Opal جزءًا حاكمًا ما لم يمكن تصدير run/artifact/receipt IDs وقراءتها آليًا.
- **Platform resilience:** توقف Opal أو تغيره لا يفقد النص أو الأدلة أو القرار التاريخي.
