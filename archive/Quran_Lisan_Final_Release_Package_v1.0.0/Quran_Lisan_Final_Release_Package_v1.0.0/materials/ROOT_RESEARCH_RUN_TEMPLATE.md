## Internal induction

1. Record observations without semantic conclusions.
2. Attribute candidate effects by root/lexeme, form, construction, roles and context.
3. Cluster operationally without treating cluster labels as definitions.
4. Freeze the primary, serious alternative and no-qualified-invariant hypotheses.
5. Select hard cases and essential neighbors.
6. Execute distinguishing and falsification searches.
7. Preserve counterevidence, failed predictions and unresolved cases.
8. Snapshot the internal result before external comparison.
