#### R03-R01 — Completion rule
كل ID معياري معرف في M01 يجب أن يظهر في هذه المصفوفة. أي Master ID جديد بلا row يجعل `MASTER_COVERAGE_MATRIX_COMPLETE = NO`.

#### R03-R02 — Test mapping rule
يمكن لحالة اختبار تغطية أكثر من قاعدة بشرط وجود expected behavior قابل للتحقق لكل قاعدة؛ الاسم المشترك وحده لا يثبت coverage.

#### R03-R03 — Status values
`COVERED / PARTIAL / NOT_COVERED / NOT_APPLICABLE`. baseline v1.1 لا يعتمد `NOT_COVERED`.
