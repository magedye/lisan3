## المصفوفة التفصيلية المنقحة
# 0. الغرض من الملحق

هذا الملحق يحوّل منهج **Quran Lisan** إلى مجموعة أسئلة مرجعية منظمة تُستخدم لتوجيه البحث، واكتشاف الفجوات، ومنع القفز إلى النتائج قبل اكتمال الأدلة.

المبدأ الحاكم:

> **لا تبدأ بالسؤال: ماذا تعني الكلمة بحسب ما نعرفه عنها؟ بل: ما الأسئلة التي يجب أن يجيب عنها القرآن نفسه حتى نستطيع بناء معنى منضبط قابل للتتبع والنقض؟**

وهذا الملحق ليس قالبًا يجب ملؤه بالكامل في كل بحث.

```text
QUESTION_MATRIX ≠ MANDATORY_SLOT_FILLING
```

بل يعمل وفق:

```text
CORE_QUESTIONS
+
APPLICABLE_MODULE_QUESTIONS
```

وأي سؤال غير منطبق يُسجل:

`NOT_APPLICABLE`

وأي سؤال لا تكفي الأدلة للإجابة عنه:

`NOT_ESTABLISHED / UNRESOLVED`

# 1. قواعد استخدام مصفوفة الأسئلة

## 1.1. لا يجب طرح كل الأسئلة دائمًا

يحدد `MODULE_ROUTER` الأسئلة المنطبقة بحسب نوع المهمة:

| نوع المهمة | الوحدات الإضافية |
| :--- | :--- |
| جذر | Root Unity + Derivation + Layer Attribution + Hard Cases |
| مفردة | Distribution + Valency + Neighbors + Contrast |
| تركيب | Syntax + Construction + Substitution |
| آية | Structure + Event/Relation + Purpose/Outcome |
| مقارنة لفظين | Distinction + Reverse + Near/Far |
| فعل عملي | Practical Reconstruction + Text/Open/Human |
| مفهوم قلبي/معرفي | Attentional Orientation |
| أثر دنيوي | Worldly Effect Evidence Gate |
| ادعاء غياب | Textual Silence + Coverage Gate |
| موضوع حساس | Sensitive Topic Protocol |
| بحث Reverse | A09 — Quran Lisan Reverse Protocol |

---

## 1.2. الأسئلة تولّد فرضيات ولا تثبتها

وجود سؤال مثل:
> ما الغاية؟

لا يعني أن هناك غاية يمكن إثباتها.

وقد تكون النتيجة:

```text
EXPLICIT_PURPOSE = NOT_ESTABLISHED
```

وكذلك:
> ما الحالة السابقة؟

لا يوجب وجود `PRE_STATE` إذا لم يثبت النص ذلك.

---

## 1.3. ترتيب الأولوية

نفّذ الأسئلة بهذا التسلسل العام:

> **ما النص المتحقق؟**  
> **ما وحدة التحليل؟**  
> **ما الذي تفعله المفردة في استعمالاتها؟**  
> **ما المعنى المحوري للجذر إن أمكن إثباته؟**  
> **ما الذي تضيفه الصيغة والتركيب والمشاركون والسياق؟**
