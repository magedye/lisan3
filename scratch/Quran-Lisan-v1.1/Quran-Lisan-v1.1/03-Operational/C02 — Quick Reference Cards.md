# C02 — Quick Reference Cards

هذه Cards **عرض مشتق**؛ لا تنشئ Claim/Evidence/Status. القواعد الحاكمة: [A14-D05] و[A15-R07].

## Root Card
`Target/Scope → ROOT_AXIAL_MEANING → ROOT_DEFINITION → Plain Explanation → ROOT_CONCEPT_MODEL → Semantic Boundary(REQUIRED/PERMITTED/EXCLUDED/UNKNOWN) → DISTINCTIVE_RESIDUE → Essential Neighbors → Layer Separation → Local Realizations → Illustrative Verses / Decisive Contexts → Hardest Case → Counterevidence → Rejection Condition → Coverage/Quality → Three Axes → Limits/Reopen`.

إذا لم تثبت النواة: `ROOT_AXIAL_MEANING=NOT_ESTABLISHED` و`ROOT_CORE_STATUS=UNRESOLVED`; لا تملأ البطاقة بالتخمين.

## Word / Term Card
`LEXEME_LEVEL_MEANING → Root Contribution → Form → Construction → Participants → Context → Local Meanings → Distribution → Neighbors → Semantic Boundary → Evidence/Counterevidence → Scope/Reopen`.

## Verse Card
`Direct Textual Meaning → Structure → Key Terms → Lexical Results → Participants → Relations → Event/State Model → Semantic Clarification → Inference → Open Possibility → Text/Open/Human → External Addition → Counterevidence → Limits → Three Axes`.

## Comparison Card
`Shared Domain → A/B → Overlap → Positive Distinctive Features → Layer of Difference → Essential Neighbors → Third Term → Substitution → Reverse → Counterevidence → NO_DIFFERENCE_ESTABLISHED if applicable → Status`.

## Reverse Card
Targets → domain → relation type → scope/negation → participant/construction control → contrast axis/boundary → third term → near/far → direct-network crosscheck → limits.

## Practical Reconstruction Card
entry → actions → restraints → boundaries → completion → post-state **only if evidenced** → `NOT_SPECIFIED` → [A08-G01] for open-space claim → Human Implementation.

## Sensitive Topic Card
neutralize question → Blind Lab → broad corpus → layers → models → freeze/prediction → counterevidence → purity → completeness → lock → optional post-lock external comparison.

## Research Record Card
`Contract → Coverage → Observations/Constraints → Hypotheses/Freeze → Evidence/Counterevidence → Neighbors/Distinctive Residue → Predictions/Failures → Dependencies → Decision → Internal Snapshot → Optional External Comparison → Reopen`.

## Memory Card
`Primary Result → Reliability → Scope → Conflict/Lifecycle → Evidence refs → Counterevidence → Dependencies → Coverage → Three Axes → Reopen conditions`.

## Final User Card
Primary result first. Then fixed/analysis/evidence/counterevidence-or-hardest-case/limits/text-open-human/epistemic status/options. Show only useful sections.
